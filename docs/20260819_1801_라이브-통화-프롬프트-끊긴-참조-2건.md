## §2. 고친 것 — 끊긴 참조 2건

둘 다 모델에게 **"저기를 봐라"라고 해 놓고 그 자리에 아무것도 없던 것**이다.
지시문 안에서 길을 잃으면 모델은 규칙을 따르는 대신 **자기 마음대로 채운다.**

### ① 규칙 1 — "**위** 선톡 질문"인데 위에 아무것도 없다

```
- 위 선톡 질문에 대한 학습자의 음성 답을 듣고 네가 스스로 모드를 정해 진행해라.
```

선톡 시드는 이 지시문에 **없다.** `call_session` 이 통화 시작 직후 `send_text_turn` 으로
**별도 턴**으로 주입한다(`seed_opening`, `persona_prompt.py:61` 주석).
Live 는 세션 내내 컨텍스트가 남아 모델이 대화 이력에서 찾아낼 수는 있지만,
문서 안에서 "위"는 끊긴 화살표다.

**고침**: 가리키지 말고 **스스로 말하게** 한다.

```
- 네가 통화 첫머리에 던진 모드 질문에 대한 학습자의 음성 답을 듣고 …
```

⚠ 질문 문구("공부할래, 수다 떨래?")를 **리터럴로 옮겨 적지 않았다** — 리터럴은 금지든
예시든 씨앗이 된다(README §3 원칙 2, call 782). 시드가 이미 그 질문을 시킨다.

### ② [대화 모드 — 착지] — "**아래** 밴드 정책"인데 실제로는 위

규칙 3 의 조립 순서는 이렇다:

```
- [모드별 언어 — 가장 중요] … 아래 밴드 정책은 …     ← "아래" 맞음
{lang_policy}                                         ← 밴드 정책이 여기 꽂힌다
- [대화 모드 — 착지] … 발판의 정도는 아래 밴드 정책이 정한다.   ← 실제론 위
```

한 글자 문제지만, 모델이 아래를 뒤지다 못 찾으면 **초급에게 댈 모국어 발판을 자기
재량으로 정한다.** `아래` → `위`.

**길이 영향**: 5,180 → 5,191자(+11). Live 는 세션 시작 1회 주입이라 턴당 원가가 아니다.

## §3. ⭐ 스냅샷 재기준화를 어떻게 했나

`tests/test_persona_prompt.py` 는 리팩토링 전 원문을 `_ORIG_INVARIANTS_TEMPLATE` 로
동결해 두고 출력이 바이트 동일한지 본다. 헤더에 **"수정 금지"** 라고 적혀 있다.

다만 이 파일엔 **선례가 있다** — 2026-07 한국어 위주 전환 때 "의도적 재기준화"를 하고
docstring 에 이유를 남겼다. 그 관례를 따랐다.

⛔ **동결본을 통째로 다시 뽑지 않았다.** 소스에 넣은 것과 **똑같은 두 치환만** 동결본에
적용했다(한 스크립트가 두 파일에 같은 replace 를 돌리고, 각 문자열이 **정확히 1회**
등장하는지 assert 한다).

> 왜 이렇게까지 하나: 통째로 재생성하면 내가 **실수로 바꾼 곳까지 같이 얼어붙는다.**
> 같은 치환만 넣으면 의도 밖의 변경은 여전히 이 테스트에서 터진다.

동결본 헤더와 두 docstring 에 재기준화 이력을 적었다(2026-07 / 2026-08-19).
