   `07-25` "rules 제거" 페이지보다 **나중**이다.
   근거: 배포 리비전 app-api `00020`(norules) < `00021`(ltsidecar),
   demo-api `00065` < `00067`, test-api `00034`(ltsidecar) > `00031`(GCP 문서).

   현재 기준은 **266 passed**.

4. 프롬프트 전문에 오타로 보이는 부분이 있다(예: 종료 시드의 `곳 딱 맞는` → `곧`).

### 레벨테스트 AI 접점 3개

| # | 역할 | 받는 것 | 하는 일 |

| ① | 비버(Gemini Live 네이티브 오디오) | 실시간 오디오 + 대본(시스템지시문·선톡시드·종료시드) | 4단 유도 사다리로 스스로 escalate. **절대 스스로 종료 안 함** |

| ③ | 통화후 판정관 (1회) | 통화 전체 전사 | 7밴드 마커로 판정 → 코드가 레벨 배정. **최종 레벨은 여기서 확정** |

> 일반통화 전용인 **④문장 추출 / ⑤문장별 TTS는 레벨테스트 경로에 없음.**
> (단 `02-infra-cloudrun.md`에서는 일반통화 기준으로 살아있는 로직으로 다룸 — 충돌 아님)

### 레벨 스킴 (넓은 5레벨)

```
_BUCKET_LEVEL = {chunk:1, a1:2, a2:3, a3:3, a4:3, mid:6, adv:10}
→ 실제 배정 레벨: 1 / 2 / 3 / 6 / 10  (그 사이 레벨은 자동 레벨업이 메꿈)
```
판정관은 **7밴드 마커 탐지는 그대로 유지**(감지 유지, 배치만 L3로 흡수) → 추후 정밀 복원 가능.

### 종료 규약 (call_session)

1. 하드 턴캡 — 답변 10개 (`LEVELTEST_BAND_MAX_ANSWERS`)
2. 비화자 결정론컷 — `nonspeaker_streak >= 5`
3. 사이드카 `should_end` + 게이트(최소 3답변 · 시간바닥 45s)

### 인프라 제약 (요약)

- `app-api`는 **`cpu-throttling=false` 유지 필수** — 통화후 파이프라인이 WS 닫힌 뒤 도는 fire-and-forget이라 true면 굶어 죽음.
- `test-api`만 `true`로 전환 완료(월 ~₩10만 절감).
- 정석 해법(미착수): 통화후 분석을 **Cloud Tasks 워커**로 오프로드 → app-api도 true 가능.
