## 3. 요청 3건 처리

### ① 엔드포인트 선택을 서버가 판정 — 요청하신 2단 구조 그대로

| 단계 | 동작 |
|---|---|
| 1순위 힌트 | 클라 JWS(`purchase_token`)의 `environment`(`Sandbox`/`Production`) → **먼저 칠 호스트**를 고릅니다 |
| 2순위 폴백 | **401 또는 404**(본문 `4040010 TransactionIdNotFound` 포함) → **반대 호스트로 1회 재조회** |
| 대칭 | 샌드박스에서 401/404 가 나오면 **운영으로도** 폴백합니다(양방향) |

- `is_sandbox` 클라 값은 기존대로 **로그·불일치 경고에만** 씁니다(`iap.py:124`)
- **호스트 문자열은 바꾸지 않았습니다** — 실측하신 두 호스트 그대로입니다(상수화만: `_APPLE_PRODUCTION_HOST` / `_APPLE_SANDBOX_HOST`)

### ② §24 구독 갱신 재조회 — **코드 변경이 불필요했습니다**

`subscription_refresh_service` 와 `iap_service` **둘 다 공용 진입점 `iap.verify()` 하나만** 부릅니다(`_verify_apple` 직접 호출 **0건**). ①의 폴백이 그대로 적용됩니다.

추정이 아니라 **시험으로 증명했습니다** — `IAP_VERIFY_ENABLED=True` 로 실제 `verify()` 를 호출해 폴백이 공용 진입점에서 도는 것을 확인하는 회귀를 추가했습니다.

⇒ 샌드박스 구독의 만료 재조회가 실패해 심사관 계정이 Free 로 떨어지는 경로는 없습니다.

### ③ 복원 · 묶음 경로 — 같은 함수를 탑니다

`storekit` · `_verify_apple` 저장소 전체 grep 결과 `core/iap.py` 와 그 테스트 파일 외 **0건**입니다. 복원(`/purchases/restore`) · 캐릭터 · 묶음 전부 `verify_and_grant → iap.verify()` 한 경로만 탑니다. 별도 애플 호출 경로가 없어 추가 적용이 필요하지 않았습니다.

## 5. ⚠ 보안 처리 — 알아두셔야 할 것

클라이언트가 보낸 JWS 를 미검증으로 읽는 건 **신뢰 경계가 반대**입니다(위조 가능). 기존 `_decode_apple_transaction` 의 면제는 「우리가 애플에 직접 물어 받은 응답」이라는 전제 하나 때문이라 여기 쓸 수 없습니다.

그래서:

- **`_apple_env_hint_unverified`** 를 **별도 함수**로 만들었습니다 — 이름에 `unverified` 를 박고, 기존 함수를 재사용하지 않았습니다
- ⭐ **클라의 `environment` 주장은 「어느 호스트를 먼저 칠까」에만 씁니다.** 지급·권한 판정에 쓰지 않습니다
- ⭐ **진짜 환경은 애플이 서명해 돌려준 응답이 정합니다**(`_is_apple_sandbox_transaction`) → 그 결과로 `store_confirmed_test` 를 세웁니다

⇒ 클라가 `is_sandbox=false` 로 보내도 **실측이 샌드박스면 샌드박스로 기록**돼 매출 집계에서 빠집니다. 기존 `is_sandbox = 클라 OR 스토어` 규율을 유지합니다(Google `testPurchase` 와 같은 축).

## 6. 회귀로 고정한 것 (신규 9건)

1. `environment=Sandbox` 힌트 → 샌드박스 호스트로 먼저 감
2. `environment=Production` 힌트 + 운영 401 → **샌드박스 폴백 200** + 폴백 로그 + 토큰 미포함
3. 운영 404(`4040010`) → 샌드박스 폴백
4. 샌드박스 401 → **운영 대칭 폴백**
5. **클라 거짓 신고 교정** — `is_sandbox=false` 인데 실측 샌드박스면 `store_confirmed_test=true`
6. 힌트 없음·JWS 파싱 실패 → 기존 동작으로 시도하고 폴백은 그대로 작동
7. 캐릭터 `kind` 도 동일 폴백
8. 호스트 문자열 불변
9. **공용 진입점(`iap.verify()`)으로도 폴백이 돈다** (②의 증명)
