## 작업 전 주의

- 편집 파일(`core/prompts/editable/*.md`)을 고치면 **`X.default.md` 도 똑같이** 고친다(동일성 시험).
- expression·freetalk 편집 파일은 **토큰 예산 96~98%** — 한 문장 넣으면 한 문장 빼야 한다.
- 편집 파일 머리말 규칙: 섹션 헤더·슬롯 유지, 금지어 증가 금지, `[` 줄 신설 금지, **리터럴 예시 금지**, **톤 부사 금지**.
- 잠금 파일(`core/prompts/locked/*.py`)은 해시 시험이 걸려 있다 — **재우님 협의 필수**.
- 고친 뒤 `docs/prompts/README.md` §8 결정 로그에 기록.
- 확인: `PYTHONIOENCODING=utf-8 conda run -n beavertalk-server python -m pytest tests/ -q`
- ⚠ **`editable/normal.md` 는 고쳐도 통화가 안 바뀐다**(P02). 일반 통화는 `chat.py` 가 프리토킹 대본(`freetalk.md`)을 재사용한다.
