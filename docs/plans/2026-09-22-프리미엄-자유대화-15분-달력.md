- [ ] **C7 자유대화 통화 세션**
  - 코스 `chat`: cur 경로 아님(진도 무영향). 지시문 = `core/prompts/freetalk.py` 의 **D8 기본 대본**(차시 블록 없이)을 재사용 + 새 블록 `[기억]`(chat_memory 의 summary·facts·next_topics — 없으면 블록 자체 생략) + `[관심사]`(회원가입 관심사 = 지금 `interests` — 없으면 생략). 새 문구가 필요하면 **새 파일** `core/prompts/chat.py`(잠금 대본 무변경).

  - 통화 끝: 문장 추출(기존 분석, C8 현지인 표현 포함) + **기억 추출** — `summarize_for_resume_text` 재사용해 topic·facts·pending 을 얻고, 관심사는 같은 호출 스키마에 `interests` 칸 추가(선택 칸, 자유대화에서만 채움) → `chat_memory_service.merge`.
  - 시험: chat 지시문에 차시 블록 없음 · 기억 있으면 [기억] 블록·없으면 생략 · 관심사 없으면 생략 · premium 이어하기 허용 · 통화 끝 merge 호출 · 진도(cur_*) 무변경.

- [ ] **C12 학습 달력 API**
  - `GET /api/v1/stats/calendar?start=YYYY-MM-DD&end=YYYY-MM-DD&tz=Asia/Seoul`(tz 없으면 `tz_offset_min`, 둘 다 없으면 UTC). start>end 면 422, 범위 최대 **400일**.
  - 집계 대상: 본인 통화, 레벨테스트 제외, **성립 통화**(학습자가 한 번이라도 말함 — 기존 `has_call_in_window` 기준 재사용). 날짜 = 통화 시작 시각의 현지 날짜.
  - 응답(필드 생략 규칙 적용):
    ```
    {
      "days": [ {"date":"2026-09-22", "sentences":6, "words":132, "call_count":2, "call_minutes":14} ],   // 통화 없는 날은 목록에 없음

      "streak_days": 12                                                                                   // C13
    }
    ```
    `sentences` = 그 날 통화에서 저장된 문장(현지인 포함, 삭제 제외). `words` = user_word_count 합(전부 NULL 이면 키 생략). `call_minutes` = total_time 합 ÷ 60 올림. `call_days` = 합계에만.
  - 시험: 하루(start=end) · 한 달 · 통화 없는 날 제외 · words 전부 NULL 이면 키 없음 · 시간대에 따라 날짜가 갈리는 통화 1건(UTC 15:30 = 서울 다음날 00:30).
