## 1. 무엇을 만드는가

- 마이페이지 억양 분석 카드 → 「취약 발음 학습하기」 진입.
- 목록 2종: **국적별 취약 발음**(억양 top1 국가의 통계) · **나의 취약 발음**(내 복습 집계).
- 학습 4단계: 이해(도해·청취) → 단어 4개(무채점·자동) → 문장 1개(무채점·자동) → 평가 1문장(채점).
- 평가 점수가 그 소리의 정확도를 갱신한다.

## 2. 소리 단위 = `sound_key`

- 형식: `onset_ㄱ` · `coda_ㄹ` · `rule_연음`.
- 자모만으로는 초성과 받침이 한 버킷에 섞인다. 위치를 키에 넣어 갈랐다.
- 모음(중성)은 1차 범위 밖이다. 조음 도해 자산이 자음·규칙만 있다.

### 2.1 이미 반영된 것 (커밋 전)

| 파일 | 변경 |
|---|---|
| `core/speechsuper.py` | `_attach_positions()` — word(=한 글자)의 자모 슬롯과 벤더 phoneme 목록을 순서로 정렬해 `position`·`sound_key` 부착. 슬롯 수 불일치면 붙이지 않음(None) |
| `core/speechsuper.py` | `sound_key(alpha, position)` 신설. 스텁의 `alpha` 를 라벨→**자모**로 통일(실경로와 같은 모양) |

| `domains/learning/service/pronunciation_service.py` | `aggregate_sounds()` 버킷 키를 `sound_key` 우선으로. 출력 `alpha` 는 `sound_label()` 라벨. 위치 없는 옛 복습은 종전대로 |
| `tests/test_speechsuper.py` | 새 키 2종 계약 반영 + 스텁 alpha 자모 단언으로 교체 |

- 벤더는 위치를 주지 않는다. 정렬 추론이 유일한 방법이다.
- 옛 복습은 `position` 부재 → `sound_key` None → 자모 버킷 유지. 데이터 마이그레이션 없음.

## 3. 저장

### 3.1 `sound_lesson` — 학습 콘텐츠 마스터

- 30행(소리 25 + 규칙 5). 출처는 `lessons.json`.
- 컬럼: `sound_key`(PK 유일) · `type`(sound/rule) · `label` · `position` · `diagram` · `card_desc` · `payload`(JSON — how_to·words·sentence·test·formula).
- 시딩 스크립트로 upsert. 앱은 DB 만 읽는다.

### 3.2 `member_sound_score` — 회원별 소리 점수

- 컬럼: `member_id` · `sound_key` · `score`(0~100) · `attempts` · `last_learned_at`.
- UNIQUE(`member_id`, `sound_key`) — 멱등 upsert.
- 평가 제출 시 갱신. 학습 전 점수는 `aggregate_sounds()` 집계값으로 초기화.

### 3.3 `national_sound_stat` — 국적별 통계

- 34개국 × 취약 소리. 컬럼: `country_iso` · `sound_key` · `share`(%) · `rank`.
- 출처는 `national_weak_sounds.json`. 시드 전용, 런타임 쓰기 없음.

## 4. API

접두사는 `/api/v1/pronunciation` 이다. `/calls` 아래 두지 않는다 — 이 기능은 통화 1건에
매달리지 않고 회원의 누적 발음과 국적 통계를 본다.

| 메서드 | 경로 | 응답 |
|---|---|---|
| GET | `/weak-sounds` | `{national:{country, items[]}, mine[], recommended}` |
| GET | `/weak-sounds/{sound_key}/lesson` | 4단계 콘텐츠 전량 + 현재 점수 |
| POST | `/weak-sounds/{sound_key}/assess` | multipart WAV → `{before, after, delta, best_score, attempts, text, char_scores, phoneme_misses}` |

- 목록의 `national` 은 `SpeakCountry.first_country`(영문 국가명)로 통계를 찾는다.
- **채점은 서버가 한다**(09-20 확정). 앱은 녹음만 올린다 — 클라가 점수를 보내면 100 을
  보내는 것을 막을 수 없었다. 평가 문장은 `sentence` 행이 없어 기존 복습 경로를 못 쓴다.
  그래서 `assess_pronunciation()` 을 직접 부르고 복습 이력은 남기지 않는다.
- 목록 노출 개수는 **5**(`LIST_SIZE`, 09-20 확정).
- 추천은 국적별 1순위 중 **80점 미만** 첫 항목. 표본 없는(None) 소리도 후보다.
- 연습 단계는 무채점이라 **제출 API 가 없다**. 기획 §6 초안의 연습 채점 호출은 폐기한다.
- 점수 출처는 둘이다 — 학습한 소리는 `member_sound_score`, 안 한 소리는 복습 집계.
  응답의 `learned` 가 어느 쪽인지 알려준다(결과 화면 「학습 전」 막대의 근거).
