## 1. 목표 & 범위
**목표** — 표현학습·프리토킹 통화가 «회원의 지금 차시» 를 기준으로 재료를 뽑고, 판정 결과를 차시별로 쌓고, 차시가 끝나면 프리토킹을 열고 다음 차시로 넘어간다. 그 과정에서 옛 학습 테이블은 한 줄도 읽지 않는다.

**MVP 범위**
1. 선별: `cur_member_progress` → 지금 차시 → 안 배운 항목(seq 순, ≤18) + 복습 채움(틀린 것→오래된 것→랜덤, 뒤에) · 예문 1개 회전
2. 저장: T16 서버 판정 결과 → `cur_member_item`(회원×차시×항목) · `cur_call.items`(결과 화면) · 통화 시작 때 `cur_call` INSERT
3. 차시 완료 → `cur_member_lesson.expression_done` → 프리토킹 열림 · 프리토킹 1회 → `freetalk_done` → 다음 차시(MIN(no) > 현재)
4. 프리토킹 지시문에 차시 재료(situation·partner·그 차시 표현 목록·probes) 주입 — 판정 없음
5. API: `GET /cur/me` · `GET /cur/lessons` · `GET /calls/{id}/result` 의 `quiz_items` 를 cur_call 에서 · `POST /__dev/cur-reset`
6. 스위치 `CUR_ENABLED`(기본 true) — false 면 옛 경로 그대로(코드 배포 없이 되돌리기)
7. 하네스 `--fix-items`/`--reset`/`--status` 를 cur_* 로 — 표현학습 2회 + 프리토킹 1회 실측

**비범위(별건)** — 레벨테스트→시작 차시 연결(그 전엔 no=1) · 앱 차시 진도 화면 · 옛 경로(learning_item 기반 표현학습·승급) 삭제 · 다국어 시드 · 무음 넛지×퀴즈(Q26) · 3.1(Q30) · 레벨1 청크 프리토킹 상황 문구 다듬기

**통화 시작 (표현학습)**
```
① progress = ensure_progress(member)  — 없으면 no=1 로 생성(별건: 레벨테스트 연결)
② lesson = progress.lesson · status = cur_member_lesson(member, lesson) or learning
③ items  = lesson_items(lesson) LEFT JOIN cur_member_item(member, lesson) → 안 배운(drilled_at NULL) seq 순 [:N]
   부족분 = review_pool(member): cur_member_item 전체 중 drilled_at NOT NULL, 현재 차시 밖 우선 없음(어느 차시든)
             ORDER BY (quiz_failed_count>0 AND quiz_passed_at IS NULL) DESC, drilled_at ASC, random()  [:N-len]
   DTO = [{item_id, obj=surface, des=meanings.en, ex=examples[seen_count % len], role, review: bool}]
④ cur_call INSERT(call_id, lesson_id, course=expression)  — 통화 시작 시점(검수 P0-4)
⑤ build_expression_instruction(items=DTO …) — 프롬프트·큐·판정(T16)은 그대로. 복습 항목도 목록에 같이 실린다(퀴즈 3개마다 동일)
```
**통화 종료 (표현학습)** — `_final_expression_progress` 뒤:
```
drilled_ids · passed_ids · failed_ids(state) → record_expression(member, lesson, call, …):
  cur_member_item UPSERT(회원×차시×항목): drilled_at(단조)·drilled_call_id · quiz_passed_at(단조) · quiz_failed_count+=1(failed, 미통과일 때) · last_quiz_call_id · seen_count+1(목록에 실린 전부)
  ⚠ 복습 항목(다른 차시 것)은 그 항목의 원 차시 행(member, lesson_of_item, item)에 적는다 — 판정 축은 «처음 배운 차시» 가 아니라 «그 항목이 속한 차시»(어휘는 1차시, 문법은 이번 목록에 실린 차시)
  cur_call.items = 스냅샷 · lesson_completed = (그 차시 cur_lesson_item 전부 drilled)
  완료면 cur_member_lesson.status=expression_done · expression_done_at (단조 — 되돌리지 않음) · expression_calls+=1
```
**프리토킹**
```
시작: status != expression_done → ServerError(code="COURSE_LOCKED", recoverable=False) 로 거절(소켓 닫힘) · 하네스·앱은 메시지 표시
      열려 있으면 cur_call INSERT(course=freetalk) · build_freetalk_instruction(lesson=brief{situation, partner, surfaces(그 차시 표현 ≤18, 복습 유도용), probes})
종료: complete_freetalk → cur_member_lesson.freetalk_done(+call_id) · progress.lesson_id = MIN(no) > 현재 (없으면 마지막 유지) — 판정 없음
```
**API**
```
GET /cur/me        {lesson:{no, code, level_no, situation, topic}, status, items_total, items_drilled, open:{expression:bool, freetalk:bool}}
GET /cur/lessons   ?level=  [{no, code, level_no, situation, status}] (내 상태 조인)
GET /calls/{id}/result  quiz_items ← cur_call.items 가 있으면 그것(없으면 옛 call.expression_result — 옛 통화 호환)
POST /__dev/cur-reset  {member_id?, lesson_no?} — cur_member_* 삭제 + progress 를 lesson_no 로 (하네스 --reset/--fix-items 가 이걸 부른다)
```
**스키마 추가 1** — `cur_member_item.seen_count smallint default 0`(예문 회전 근거). 회원 행 0 이라 a1c2d3e4f5b6 을 고쳐 재적용(1단계와 같은 절차) — 2단계 첫 커밋.

## 5. 리스크 & 결정 사항
- **복습 항목의 판정 축** — 복습으로 실린 항목의 passed/failed 를 «그 항목의 차시 행» 에 적는다(위 ⚠). 문법이 두 차시에 속하면 이번 목록에 실린 쪽 차시. 검수 요청 사항.
- **프리토킹 잠금 UX** — 지금 앱 개발자도구 버튼은 잠금을 모른다 → 서버가 COURSE_LOCKED 로 끊으면 앱은 «연결 실패» 로 보인다. MVP 는 그대로 두고(dev 버튼), 정식 화면(비범위)에서 /cur/me 로 버튼을 가린다.
- **첫 차시 = 청크 15개(레벨1)** — 한 통화 15개, 복습 0. 청크 프리토킹 상황 3개는 임시 문구(결정 12).
- **CUR_ENABLED 스위치** — 옛 경로가 남아 있어 두 경로가 공존한다. 운영에서 새 경로가 안정되면 옛 표현학습 경로 삭제는 별건.
- **seen_count 추가** — 1단계 «안 읽는 컬럼 금지» 원칙과 맞다(예문 회전이 읽는다). 회원 행 0 이라 마이그레이션 재적용으로 처리.
- **가정** — 레벨테스트와 무관하게 새 회원은 no=1 부터(별건) · 프리토킹은 통화 1회 = 완료(중간 끊김도 완료로 본다: freetalk_done 은 cur_call 이 생긴 통화가 정상 저장되면 찍는다 — 60초 미만 끊김은 미완료로 둘지 검수 질문).
