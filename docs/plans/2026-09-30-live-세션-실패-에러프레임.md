## 1. 목표 & 범위

**목표**: 통화가 예외로 죽었을 때 학습자가 «이유 없이 끊김» 을 보지 않게 한다.

**지금 무슨 일이 나나** (배포본 실측):
- `call_session.py:4890` 의 `async with live_session_factory(...)` 가 예외 → `:4209` 「최종 방어선」이
  `logger.exception` 만 찍는다 → `ws_router.py:100~109` finally 가 소켓을 닫는다.
- ⇒ 앱은 `call_started` 를 이미 받은 뒤 **아무 설명 없이 소켓이 끊긴다.**
- 통화 **시작 전** 관문 4종은 이미 에러 프레임을 보낸다:
  `ALREADY_IN_CALL`(3210 · 이어하기 재확인 3574) · `DAILY_LIMIT`(3277) ·
  `RESUME_UNAVAILABLE`(3587) · `COURSE_LOCKED`(3650).
  **빠진 곳은 «세션이 열린 뒤의 예외 경로» 딱 하나다.**

**범위(MVP)**: 그 한 자리에 `ServerError` 를 보낸다. 끝.

**비범위**:
- 예외 원인별 분류(동시 한도/인증/네트워크) — 원인 판별을 정교하게 깎지 않는다.
  ⛔ 오늘 C9 에서 「조건별 예외를 정교하게 깎으려는 시도가 버그의 본체」였던 것과 같은 함정이다.
  운영자용 원인은 `logger.exception` 이 이미 전부 남긴다.
- 재시도·재연결 — 앱은 `error` 를 받으면 `_teardown` 한다(재연결 경로를 타지 않음).
- 정상 종료 경로(`_CallFinished` · `_FragmentEnd` · `_ClientDisconnect` · `TimeoutError`)는 **손대지 않는다**.

## 2. 설계

### 2-1. 어디에 넣나 — 「최종 방어선」 안, finally 보다 먼저

`except Exception` 핸들러 안에 넣는다. 그러면 학습자는 **즉시** 듣고, 무거운 통화후 파이프라인
(`finally`)은 그 뒤에 그대로 돈다.

⚠ **통화후 저장이 깨질 위험이 없음을 확인했다**: 앱이 `error` 를 받으면 소켓을 닫지만,
`finally` 의 클라 송신은 전부 `contextlib.suppress(Exception)` + `client_state` 확인이다
(`_finish_call`, `call_session.py:7418~7450`). 닫힌 소켓에 쓰려는 시도는 조용히 무시된다.
분석·전사·usage 저장은 소켓과 무관하게 진행된다.

### 2-2. 두 가지 code — 신호는 이미 있다

`state.beaver_turns`(비버가 실제로 말한 턴 수)로 가른다. 새 상태 변수를 만들지 않는다.

| 조건 | code | 뜻 |
|---|---|---|
| `beaver_turns == 0` | `LIVE_START_FAILED` | 통화가 **시작도 못 했다**(세션 열기 실패 포함) |
| `beaver_turns > 0` | `CALL_INTERRUPTED` | 통화 **중에 깨졌다** |

⇒ 사용자가 다음에 할 일이 다르다(다시 걸기 / 결과 화면). 그래서 둘로 나눈다.

### 2-3. 문구는 앱이 현지화한다 (⚠ 앱 작업 필요)

앱 수신부(`normalcall_controller.dart:4955`, `serverErrorMessage` `:6403`)를 읽어 확인했다:

```dart
switch (msg['code']) {
  'DAILY_LIMIT' => l10n.callDailyLimit,
  'ALREADY_IN_CALL' => l10n.callAlreadyInCall,
  _ => (msg['message'] as String?) ?? l10n.callErrorGeneric,
}
```

- 앱은 `error` 를 받으면 **로그를 남기고 화면에 띄운다**(`CallPhase.error`) ⇒ 이 수정은 실제로 사용자에게 닿는다.
- **미지 code 는 서버 `message` 를 그대로 띄운다.** 서버 문구는 한국어인데 **사용자는 외국인 학습자**다
  ⇒ `DAILY_LIMIT` 과 같은 정본 패턴(**서버는 code, 앱이 현지화**)을 따른다.
- 서버 한국어 `message` 는 **구버전 앱 폴백**으로만 둔다.
- ⇒ **앱팀 요청**: `LIVE_START_FAILED` · `CALL_INTERRUPTED` 두 code 에 현지화 문구 추가.
  그때까지 외국인 사용자는 한국어를 보지만, **침묵보다는 낫다**(현 상태 = 아무것도 안 보임).

## 4. 수용 기준

1. 세션 열기가 실패하는 통화에서 클라가 `{"type":"error","code":"LIVE_START_FAILED"}` 를 받는다.
2. 통화 중 예외로 죽으면 `CALL_INTERRUPTED` 를 받는다.
3. **정상 종료 4경로의 바이트가 변하지 않는다** — `call_ended`·`fragment_saved` 순서·내용 무변경(R4).
4. 소켓이 이미 닫혀 있으면 조용히 넘어간다(추가 예외 0).
5. 에러 프레임 송신이 통화후 저장(전사·분석·usage)을 막지 않는다.
6. `tests/test_normalcall_ws.py` 전량 통과.
