## 1. 목표 & 범위
- 목표: Pro·Max 통화가 5분마다 **끊긴 느낌 없이** 이어진다 — 다이얼로그·작별·«이어서 할게» 0.
- 범위: 표현학습·프리토킹(cur 경로) 우선. 일반 통화는 같은 코드로 다음 단계. 레벨테스트 제외(3분 캡·조각 없음).
- 비범위: 조각 수·플랜 정책 변경(Free 1 / Pro·Max 3 그대로) · Gemini 세션 핸들 승계(안 한다 — 텍스트 브리프 재개).

## 2. 흐름 (클라 주도 — 서버는 길이를 모른다)
```
조각 k (k<3)
  5:00 도달 → 클라 «전환 대기» 상태(아무 표시 없음, 타이머 누적)
  사용자 발화 → 비버 응답 스트리밍 → turn_end 수신
  → 클라: 재생 버퍼는 계속 재생 · 소켓 close(1000)  → 서버 _ClientDisconnect → 조각 저장·요약(기존)
  → 클라: 즉시 새 WS 연결 start{continues_call_id, silent_resume:true, course/plan_override 동일}
  → 서버: resume_call 검증 → 브리프(resume_materials, 없으면 즉석) → Live open → call_started
        ⛔ seed_resume 안 넣음 — 비버는 사용자 첫 발화를 기다린다
  → 재생 끝 → 마이크 열림(소켓 미준비면 프리버퍼 → open 뒤 flush)
5:00 뒤 사용자가 말 안 함 → 서버 무음 3단(넛지→확인→작별 종료) 그대로 → 클라 결과 화면
조각 3: 15:00 뒤 사용자 발화 → 응답 turn_end → 클라 close → 결과 화면 (재연결 없음)
Free: 5:00 → 기존 시트(구독 유도)
```
- 서버 백스톱은 그대로: 540초 절대(`ABSOLUTE_CALL_TIMEOUT_S`) — 클라가 9분 안에 못 갈아 끼우면 서버가 끊는다(방어).
- 조각 저장/요약: 클라 close 시점에 서버가 저장(실측 ~0.3s) + 요약 fire-and-forget. 재연결이 앞지르면 `resume_materials` 가 즉석 생성(기존, 체감 0). 저장 레이스 방지로 클라는 close 뒤 **≥300ms** 후 start 를 보낸다(재생 중이라 체감 0).

## 4. 수용 기준
- 조각 경계에서 비버 발화: 작별 0 · «이어서» 0 · 조각2 첫 턴은 사용자 발화 뒤에만.
- 사용자 체감: 다이얼로그 0 · 재생 끊김 0 · 마이크 열림 뒤 첫 발화 유실 0(프리버퍼).
- 진도: 조각마다 record_expression(recorded_fragment) · 통과 재출제 0 · 오답 앞줄(H6).
- Free: 종전과 픽셀·프레임 동일.

## 5. 리스크
- 재연결 실패(네트워크): 클라는 2회 재시도 → 실패 시 지금의 «이어하기» 시트로 폴백(사용자에게 버튼).
- 요약 즉석 생성 ~2s 가 재생보다 길면 첫 발화 뒤 응답이 늦어 보인다 → 조각 진행 중 1분 flush 에 요약 갱신을 얹는 것은 2차.
