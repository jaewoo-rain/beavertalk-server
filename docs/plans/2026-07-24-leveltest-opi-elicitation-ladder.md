## 0. 한 줄 요약
레벨테스트를 **OPI(구술능력 인터뷰)식 적응형 검사**로 바꾼다. 비버가 **레벨별 문법 마커를 요구하는 질문으로 유도**하며 한 단계씩 올리고, **유도해도 그 마커를 못 내면 거기가 천장 = 레벨**. 판정관은 산출된 마커를 탐지(마커 체크리스트 + 변주 게이트). 판정과 종료가 **같은 신호(천장)**로 통일된다.

## 1. 배경 & 문제 (QA 190콜로 실증)
- **옛 4버킷 판정관**은 "문장 만들면 다 L3"라 A1~B1을 전부 L3로 붕괴시킴(변별력 0). QA 데이터로 확인: 기초단문(A1)·A2·L4_A3·L5_A4·L6_중급(B1) → 전부 L3.
- **마커 기반 6버킷 판정관**(초안)은 골든 전사에서 초급을 정밀 분리(초급 구간 100%, 전체 97%). → 마커가 맞는 신호.
- **그러나 마커 "탐지"만으론 부족**: 고급자(유창한 복문·추상)가 B1 마커(-다고 하다·피동)를 안 써서 L4/L5로 저평가됨. **원어민도 아무 상황에서나 고급 마커를 안 쓴다** — 그 마커가 필요한 질문을 받아야 자연스럽게 나온다.
- 결론: **탐지 + 유도가 짝**이어야 한다. 자유대화만 보면 상급자도 마커를 안 뱉어 저평가된다.

## 2. 핵심 원리 (2축 → 유도로 수렴)
실력엔 두 축이 있다: ①문법 range(마커) ②유창성·담화. 초급은 ①이 거의 전부(길이는 함정 — 초보가 5분 떠들어도 A0), 고급은 ②가 중요. 그러나 ②를 "넘겨짚기"보다 **필요한 마커를 요구하는 과제로 직접 검증**한다(OPI). 진짜 고급자는 "친구가 뭐라고 했어요?"에 `-다고 했어요`로 답한다. 유도해도 못 내면 진짜 그 아래다.
- **마커 = 바닥(필수·충분조건)**: 특정 마커를 productive+다양하게 내면 그 레벨.
- **유도 = 천장 탐색**: 다음 레벨 마커를 요구하는 질문으로 밀어 올려, 못 내는 지점이 천장.
- **변주 게이트**: 같은 것 반복/긴 문장 하나 암기는 낮게 캡(게이밍 방지). 검증됨(반복충·암기긴문장충 → L2).

## 3. 레벨 스킴 (버킷 → 앱 레벨 1~13)
초급은 촘촘히(사용자 몰림), 중급·고급은 각 1칸 coarse(자동 레벨업이 채움).

| 버킷 | 앱 레벨 | 커리큘럼 |
|---|---|---|
| chunk | **1** | A0 생존회화(정형표현·단어) |
| a1 | **2** | A1 초급1 |
| a2 | **3** | A2 초급2 |
| a3 | **4** | A3 초급3 |
| a4 | **5** | A4 초급4 |
| mid(B) | **6** | 중급 B1~B4 (coarse) |
| adv(C) | **10** | 고급 C1~C4 (coarse) |

→ 7~9, 11~13은 레벨테스트로 직접 배치하지 않고 자동 레벨업으로 도달.

## 4. 마커 체크리스트 (판정관 탐지 기준 — 커리큘럼 실항목 근거)
각 레벨은 "바로 위 레벨 마커의 부재"로 상한이 정의된다.
- **chunk(L1)**: 정형표현(안녕하세요·감사합니다·이거 주세요)·숫자·이름·단어, 또는 조사·활용 없는 전보식 나열('저 서울','김치 좋다'). 새 문장 생성 없음.
- **a1(L2)**: 조사(을/를·이/가·에·에서)+현재/과거 활용 종결(-아요/어요·-았/었어요·N이에요)로 기초 단문. `고`·`지만`·`안`까지. (A2 마커 없음)
- **a2(L3)**: +이유 `-아서`, 미래 `-(으)ㄹ 거예요`, 희망 `-고 싶다`, 조건 `-(으)면`, 진행 `-고 있다`, 능력 `-(으)ㄹ 수 있다`, 현재관형 `-은/-는 N`.
- **a3(L4)**: +명사간접 `N(이)라고 하다`, 추측 `-(으)ㄴ/는 것 같다`·`-겠-`, 이유 `-(으)니까`, 비교 `-보다`, 과거/미래 관형 `-(으)ㄴ N`·`-(으)ㄹ N`, 명사화 `-는 것`, 배경 `-는데`, 나열 `-거나`·`-다가`.
- **a4(L5)**: +경험 `-(으)ㄴ 적 있다`, 허락 `-아도 되다`, 변화 `-게 되다`·`-아지다`, 순서 `-기 전에`, 의도 `-(으)ㄹ까 하다`, 반말 `-다`.
- **mid(L6)**: 동사 간접화법 `-다고/-냐고/-자고 하다`, 전언체 `-대(요)`, 피동 `-이/히/리/기-`, `-느라고`·`-자마자`·`-더니`, 목적 `-기 위해`, 사동 `-게 하다`.
- **adv(L10)**: 격식·문어체, 논증·인용 확장, `-(으)ㅁ에도 불구하고`·`-(으)ㅁ에 따라`·`N을 통해` 등 C급, 추상/사회 주제를 길고 논리적으로.
- ★ 간접화법 형태 구분: 명사인용 `N(이)라고 하다`=a3 / 동사인용 `-다고/-냐고/-자고 하다`=mid.

## 5. 유도 질문 사다리 (비버 — 이게 핵심 신규)
비버가 한 단계씩 올리며, 각 rung은 **그 레벨 마커를 요구하는 질문**. (질문은 학습자 모국어로, 답은 한국어로 유도)

| rung | 목표 | 유도 질문(예) | 나와야 할 마커 |
|---|---|---|---|
| 0 | L1 | "한국어로 인사할 수 있어요?" | 정형표현 |
| 1 | L2 | "이름은요? 어디 살아요? 어제 뭐 했어요?" | N이에요·-아요·-았어요·조사 |
| 2 | L3 | "왜요?" / "주말에 뭐 **할 거예요**?" / "뭐 **하고 싶어요**?" | -아서·-ㄹ거예요·-고싶다 |
| 3 | L4 | "저 사람들 뭐 하는 **것 같아요**?" / "이거 한국어로 **뭐라고 해요**?" / "A랑 B 중 뭐가 더?" | -것같다·N이라고·-보다 |
| 4 | L5 | "한국 음식 **먹어 본 적 있어요**?" / "여기서 사진 **찍어도 돼요**?" / "한국어 배우고 뭐가 **달라졌어요**?" | -ㄴ적있다·-아도되다·-게되다 |
| 5 | L6 | "친구가 **뭐라고 했어요**?" / "그 문제 어떻게 **해결됐어요**?" / "왜 늦었어요?" | -다고했어요·피동·-느라고 |
| 6 | L10 | "요즘 관심 있는 사회 문제? **왜 중요하다고 생각해요**? 근거는?" (추상 논증) | 격식·논증·복문 다양 |

## 6. Escalation · 천장 · 종료 (아키텍처: 비버 자율 + 서버 관측 — 기존 유지)
- **비버(자율 escalate)**: 시스템 프롬프트에 사다리 탑재. "rung N을 성공(목표 마커 산출)하면 rung N+1 질문. 유도했는데도 못 내면 편하게 화제 마무리(단, 종료는 서버)."
- **성공 판정**: 그 rung 목표 마커를 productive+다양하게 산출(변주 게이트 통과).
- **실패**: 유도해도 목표 마커 못 냄(모국어로 답/회피/못함). **같은 rung 2회 유도 실패 → 그 rung 미달 → 천장 = 직전 성공 rung 레벨.**
- **서버 사이드카(판정관)**: 매 답변 마커 탐지 → 관측 최고 마커 추적. 다음 rung 마커가 유도 후에도 안 나오면 **천장 확정 → 종료 시드 주입**. (기존 obs_max/plateau를 "마커 천장"으로 대체·단순화)
- **종료 통일**: "escalate 실패 = 천장 = 종료" 한 신호로. → 단어나열충을 179초까지 붙잡던 문제 해소(마커 천장 즉시 확정 → 짧게 종료).
- **안전장치 유지(R4 불변식)**: 절대 시간 백스톱(3분 캡·540s), 2펌프, barge-in off, 종료 시드 서버 독점.

## 7. 판정관(탐지) 스키마 (초안 검증됨 — judge6_score.py)
- 출력: `answer_language_ok`(언어 게이트) → `distinct_structures`(변주 게이트: ≤1이면 낮게 캡) → `top_markers`(근거 구절 인용) → `band`(chunk/a1/a2/a3/a4/mid/adv) → `reason`.
- band → level: `_BUCKET_LEVEL = {chunk:1, a1:2, a2:3, a3:4, a4:5, mid:6, adv:10}`.
- 통화중 사이드카(`judge_leveltest_turn`)와 통화후(`LevelAssessment`/`_place_from_band`)가 같은 마커 taxonomy 공유.

## 10. 검증 계획 (세 톱니: 유도 → 판정 → QA 분리 확인)
★ 핵심: **고정 대본 페르소나로는 "비버 유도"를 검증 못 함**(페르소나가 비버 질문을 무시하고 대본만 읽음). 유도를 검증하려면 **비버 질문에 반응하는 "능력 상한 학습자"**가 필요.

| 테스트 | 페르소나 | 검증 대상 | 방식 |
|---|---|---|---|
| 판정관 단위 | 고정 대본(현재) | 마커→레벨 분리 | 골든 전사 190 + judge6_score.py 재채점(배포無, 97% 검증됨) |
| **유도+판정 통합** | **능력 상한 LLM 학습자(신규)** | 비버 유도 + 판정 함께 | LLM학습자 ↔ 비버프롬프트 + 판정관 텍스트 시뮬 |
| 최종 | 능력 상한 학습자 | 실음성 재현 | 음성 콜 소량 |

- **능력 상한 학습자**: LLM이 "레벨 N까지만 아는 학습자"를 연기 — 비버의 실제 유도 질문에 맞춰 rung N 마커까진 산출, rung N+1 요구엔 회피/실패. 기대: 시스템이 천장 N 찾아 **레벨 N 배치**. 못 찾으면 유도/판정 결함 노출.
- **세 톱니 동시 검증**: ①비버가 L_N 학습자를 rung N까지 끌어올렸나 ②판정관이 그 마커로 L_N 판정했나 ③"L_N 학습자 → 시스템 L_N" 나오는가(QA 분리).
- **빌런 = 능력상한 + 버릇**: 반복충(L3 능력·한 문장만 반복), 암기긴문장충(L1 능력·긴 문장 하나 암기), 코드스위칭충(L3 능력·영어 섞음), 딴소리충(L3 능력·화제 이탈) → 유도·판정·대화흐름(차원 B) 함께.
- **텍스트 시뮬 = /loop 자동 튜닝 자리**: LLM학습자↔비버↔판정관 전부 텍스트라 배포·음성 없이 초 단위. 프롬프트(유도·판정) 고치고 재시뮬 → 7레벨 분리 나올 때까지 루프.
- **대화행동(차원 B) 채점관**: 같은 시뮬 전사에 — 초보 짧게/고급 어렵게 유도했나, 빌런 흐름 안 깨졌나, 한국어 유도·역할 유지·고쳐주기 안 함·종료 매끄러움.
- **결정 규칙**: 텍스트 시뮬에서 7레벨 분리 + 실음성 소량 재현 → 확정. 특정 경계 계속 섞이면 해당 구간 병합(폴백).
