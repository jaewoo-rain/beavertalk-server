## 3. [판단] dev 도구인데 지금도 유용한가 — **bt-back 이 정한다**

### 3-1. 실험용 덮어쓰기 3종 — **지금도 동작하고, 테스트가 쓴다**

| 대상 | 위치 | 사실 |
|---|---|---|
| `CASCADE_TTS_VOICE_OVERRIDE` | `config:427` · `session:3594` | 값이 있으면 **DB 캐릭터 음색을 무시**하고 이긴다. `test_cascade_db_context.py` 5곳이 이 우선순위를 회귀로 지킨다 |
| `CASCADE_LOCALE_OVERRIDE` | `config:428` · `session:3389` | 회원 모국어를 무시. 회귀 1곳 |
| `CASCADE_TARGET_LANGUAGE_OVERRIDE` | `config:429` · `session:3373` | 학습 대상을 무시. 회귀 1곳 |

⭐ **만든 이유가 지시였다**: "사장님이 데모 화면에서 언어를 바꿔 실험하신다"(설계 §, 세션 주석).
⚠ 다만 **데모 화면에 음색·언어 선택 UI 는 없다**(2026-08-12 확인, config 주석에도 적혀 있다)
  — 실험은 **env 를 바꿔 재배포**해야 한다. 그 수고를 감수하고 남길지가 판단 지점이다.
⚠ 셋 다 기본이 **빈 값**이라 켜지 않으면 아무 일도 안 한다(위험은 낮다).
⇒ 내 의견: **남긴다.** 비용이 0(빈 값)이고, 지우면 "DB 값 대신 이걸로 들어 보자"가 불가능해진다.
  다만 **이름에 `_OVERRIDE` 가 붙어 있어 헷갈리는 쪽은 아래 3-2 다.**

### 3-2. ⚠⚠ `CASCADE_TTS_VOICE` — **"안 먹는다"가 아니라 "조건부로 먹는다"**

네가 확인해 달라고 한 자리다. 코드는 이렇다(`session:3607`):

```python
return self._voice or (settings.CASCADE_TTS_VOICE or "").strip() or None
```

⇒ **덮어쓰기가 아니라 폴백**이다. DB 캐릭터에 음색이 있으면 그게 이기고(그래서 실통화 로그가
`음색=Leda 출처=DB`), **DB 음색이 없을 때만** env(`Sulafat`)가 나온다.

🔴 **그래서 언젠가 튀어나온다**: `character.voice_id` 가 NULL 인 캐릭터로 통화하면 그 캐릭터
목소리가 아니라 **Sulafat** 이 나온다. 에러는 없고, 로그의 `출처=` 만 다르다.
⇒ 선택지 둘, **bt-back 이 정해라**:
  (a) env 값을 **비운다**(코드 유지) — 음색이 없으면 언어 기본값으로 간다. 가장 조용하다
  (b) 코드에서 이 폴백을 없앤다 — 그러면 데모(회원 없음) 경로에 음색이 사라진다
내 의견은 **(a)**: 코드는 폴백으로 옳고, **env 에 값이 박힌 게 문제**다.
⚠ 같은 성질이 `CASCADE_TTS_LANGUAGE=en`(demo-api)에도 있다 — DB locale 이 있으면 지지만,
  없으면 en 으로 간다. 이건 지금 사용자가 영어권이라 **우연히 맞다**. 우연에 기대는 상태다.
