# TTS 벤더 비교 — "구글 TTS 를 바꿔야 하나"

조사 2026-08-07 04:43 · 지시 bt-back(사장님) · ⛔ 조사만, 구현 없음

---

## 결론 먼저: **바꾸지 않는다.** Chirp3-HD 를 유지한다

세 가지가 겹쳐서 그렇다.

1. **더 싼 외부 벤더가 없다.** 조사한 6곳 중 Chirp3-HD($30/1M자)보다 싼 곳은 **한 곳도 없었다.**
   Azure 는 표기상 싸 보이지만 **한국어를 문자 2개로 센다** → 실질 $32/1M. Cartesia $46.7,
   ElevenLabs Flash $50. OpenAI 만 절반쯤이나 **토큰 과금이라 실단가가 안 잡힌다**(§4).
2. **구글 안에서 등급을 낮추면 스트리밍이 죽는다.** 공식 문서 원문:
   *"Streaming Cloud Text-to-Speech is only compatible with Chirp 3: HD voices."*
   Neural2($16)·Standard($4)는 **`StreamingSynthesize` 자체를 못 쓴다.** 지금 첫소리가 이미
   예산 초과(2.7초)인데 여기서 더 나빠진다.
3. **아껴지는 돈이 작다.** 15분 통화 TTS 는 $0.18 이다. **공짜로 만들어도 $0.44 → $0.26.**
   Live($1.87) 대비 −76% 는 이미 확보돼 있고, 여기서 더 깎는 건 −5%p 짜리 싸움이다.
   그 −5%p 를 위해 **발음 품질·목소리 정체성·지연**을 건다.

⭐ 그리고 지금은 **TTS 요금이 사실상 0 원**이다 — Chirp3-HD 무료 한도가 **월 100만 자**인데,
우리 실측 400자/분이면 **15분 통화 약 166건/월**(5분 통화면 약 500건)까지 공짜다. 현재 사용량은
그 안이다. **지금 벤더를 바꾸면 0원을 0원으로 바꾸면서 리스크만 진다.**

**진짜 레버는 TTS 벤더가 아니다** — §7 을 봐라(STT 53%, 그리고 문자 수 자체).

## 1. 전제 — 코드에서 확인한 제약 4개

| # | 제약 | 근거(코드/DB) |
| --- | --- | --- |
| 1 | 캐릭터 음색이 Chirp3-HD **이름 체계**에 묶여 있다 | `core/tts.py:52-58` `_CHIRP3_HD_VOICES` 30종 = Gemini Live 프리빌트 보이스명 |
| 2 | **6개 언어**를 덮어야 한다 | `core/languages.py` ko·en·ja·zh·fr·vi |
| 3 | 어학 앱 — TTS 가 **학습자가 따라 하는 발음 모델** | 제품 성격 |
| 4 | **스트리밍 + raw PCM** 이 필요하다 | `core/tts.py::synthesize_stream`(cascade-voice), `PCM`/24kHz |

### 1-1. 음색이 묶인 자리는 **셋**이다 (이전 비용의 핵심)

같은 이름이 세 곳에서 쓰인다:

| 쓰이는 곳 | 무엇 |
| --- | --- |
| Gemini **Live 통화** | `voice.name`("Fenrir") 을 그대로 Live 에 넘긴다 |
| **캐스케이드 TTS** | `ko-KR-Chirp3-HD-Fenrir` 로 조립(`_resolve_voice`) |
| **표현 TTS**(통화후 복습 오디오) | 같은 함수, 같은 이름 |

→ **캐스케이드 TTS 만 벤더를 바꾸면 같은 캐릭터가 통화에서와 복습 오디오에서 다른 목소리로 들린다.**
그리고 Live 로 되돌아갈 일이 생기면 또 달라진다. **한 캐릭터 = 한 목소리라는 약속이 깨진다.**

### 1-2. DB 실측 (SELECT 집계만)

- `character` **5개**, 실제 쓰이는 음색 **5종**(Fenrir·Leda·Sadachbia·Sulafat·Vindemiatrix)
- `voice` 카탈로그 **30행** = `_CHIRP3_HD_VOICES` 30종과 일치

→ 이전 비용(음색 재매핑)은 **최소 5종**(현재 캐릭터), 카탈로그를 유지하려면 **30종**을 새 벤더에서
다시 고르고 성별·인상까지 맞춰야 한다. 코드 작업보다 **사람이 듣고 고르는 일**이 크다.

## 3. 탈락 — 1차 필터(언어·스트리밍)에서 걸린 곳

- **Deepgram Aura-2**: en·es·de·fr·nl·it·ja — **한국어 없음.** 어학 앱의 주력 언어가 빠진다. 즉시 탈락.
- **Naver CLOVA Voice**: ko·en·zh·ja·es — **프랑스어·베트남어 없음.** 한국어 발음은 좋을 수 있으나
  6개 언어를 못 덮으므로 **단독 대체 불가**. (한국어 전용 보조로 쓰는 안은 §6)
- **Google Neural2 / Standard**: 가격은 매력적이나 **스트리밍 API 자체가 안 된다.**

## 4. OpenAI 만 따로 — 싸 보이지만 **단가를 못 잡았다**

`gpt-4o-mini-tts` 는 문자당이 아니라 **토큰 과금**이다(입력 $0.60/1M tok + 출력 오디오 $12/1M tok).
"문자로 환산하면 약 $15/1M" 이라는 추정이 돌아다니지만, **실청구가 광고 단가의 6.15배로 나왔다는
감사 보고**가 있다. 즉 이 칸의 숫자는 **비교표에 넣을 자격이 아직 없다.**
쓰려면 실통화 1건으로 실청구를 재보는 게 먼저다(그 계기판은 이미 우리가 갖고 있다 — `usage_engine`).

## 5. 지연(TTFB) — 원가보다 이게 더 큰 이유가 될 수 있었는데, **못 쟀다**

- 지금 **첫소리 2.7초**로 예산(1.5~2.5초)을 넘는다. 그런데 그 2.7초 중 **TTS 몫이 얼마인지 안 갈랐다.**
  STT 확정 대기 + LLM 첫 토큰 + TTS 첫 조각이 다 섞여 있다.
- 공개 벤치 기준 TTFB: Cartesia Sonic **~40~190ms**, ElevenLabs Flash **~75~264ms**,
  Deepgram Aura-2 **<200ms**, 구글·Azure·OpenAI 등 범용 클라우드 **150~300ms**.
- ⭐ **범위가 100~250ms 다.** 2.7초 중 이걸 다 줄여도 **0.2초 안팎**이다. 즉 지금의 지연 문제는
  **TTS 벤더 문제가 아닐 가능성이 높다.** 벤더를 바꾸기 전에 **2.7초를 구간별로 쪼개는 계측이 먼저다.**
  (거꾸로, 쪼개 봤더니 TTS 가 1초 이상을 먹고 있다면 그때 Cartesia 가 진짜 후보가 된다.)

## 6. 발음 품질 — ⛔ **못 쟀다**

이 조사에서 **한 문장도 들어보지 않았다.** 워크트리에 크레덴셜이 없고, 벤더 계정도 없다.
공개 Elo·리더보드는 대부분 **영어 중심**이라 한국어 발음의 근거로 쓰기 어렵다.

**이건 이 조사의 가장 큰 구멍이다.** 어학 앱에서 TTS 는 학습자가 따라 하는 발음 모델이고,
그 축을 못 잰 채로 벤더를 바꾸자는 결론은 낼 수 없다. **"안 바꾼다"는 결론이 이 구멍과 정합적이다** —
품질을 못 쟀으면 이미 품질이 검증된 쪽(실제로 통화가 돌아가고 있는 Chirp3-HD)에 남는 게 맞다.

재려면: 같은 한국어·영어 문장 5개를 후보 3곳에서 뽑아 **블라인드로 듣고 고르는** 30분짜리 작업.
한국어 원어민 판단이 필요하다(사장님). 필요하면 그것만 따로 요청해라.

## 7. ⭐ 그래서 어디를 봐야 하나 — 세 가지, TTS 벤더보다 크다

실측 원가 구성(104.2초): **STT 53% / TTS 41% / LLM 7%**.

1. **STT 가 더 크다(53%).** `google-stt-v2` 는 **흘려보낸 오디오 초**로 과금된다 —
   즉 **사용자가 말 안 하는 침묵까지 낸다.** 스트림을 말할 때만 여는(VAD 게이팅) 쪽이
   벤더 교체보다 절감폭이 클 수 있다. 우리 계기판에 `stt.sent_audio_s` vs `billed_sum_s` 가
   이미 따로 잡혀 있다 — **그 둘의 차이를 먼저 봐라.** 데이터가 이미 있다.
2. **문자 수 자체(TTS·LLM 동시 절감).** 비버 발화가 20% 짧아지면 TTS·LLM 출력이 같이 준다.
   **벤더 교체 0원, 리스크 0, 프롬프트만 고치면 된다.** 게다가 어학적으로도 학습자 발화 비중이
   느는 건 이득이다. 단 재접지 문구가 길어지면 반대로 간다(내 작업과 충돌 지점).
3. **무료 한도.** Chirp3-HD 월 100만 자 = 15분 통화 166건. 지금은 그 안이다.
   **한도를 넘기 시작하는 시점**이 이 조사를 다시 열 진짜 트리거다.

## 9. 못 잰 것 (정직하게)

1. **발음 품질** — 한 문장도 안 들었다. 이 조사의 최대 구멍(§6)
2. **2.7초의 구간별 분해** — TTS 몫을 안 갈랐다. 지연 판단의 전제가 비어 있다
3. **Naver CLOVA 단가** — 공식 문서는 찾았으나 가격표 본문을 못 뽑았다(fr·vi 미지원으로 어차피 탈락)
4. **OpenAI 실단가** — 토큰 과금이라 문자당 환산이 추정이고, 실청구 6배 보고가 있다
5. **ElevenLabs 의 베트남어 지원 여부** — "32개 언어"만 확인, 목록 원문 미확인
