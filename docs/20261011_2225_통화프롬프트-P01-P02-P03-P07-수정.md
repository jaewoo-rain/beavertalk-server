## P01 — 모국어 라벨표 15키 누락
- 사실: `core/prompts/common.py:43` `LOCALE_LABEL` 15키 · 앱 `beavertalk-flutter/lib/l10n/app_*.arb` 30개.
  빠진 15개(bn fi fil hi hu it kk km ky ms my ne si tr ur) 회원은 `locale_label()` 폴백으로 설명·교정·요약이 영어.
- 확인: Gemini Live 지원 99개 언어(ai.google.dev/gemini-api/docs/live-guide)에 15개 **전부** 있음 → 전부 추가.
- 수정: 표에 15키 추가(기존 «한국어명(자국어명)» 형식). 표 하나가 대본·요약 언어(`summary_lang_for`)·번역
  (`text_translate.language_name`)의 단일 출처라 다른 코드는 무변경. 기존 15개 로케일의 대본 바이트는 불변.
- 시험: `tests/test_display_i18n.py` 가 «표 밖» 예시로 `ne` 를 쓴다 → 앱에도 없는 `sw` 로 교체 + `ne` 양성 케이스.

## P02 — `editable/normal.md` 가 실통화 경로에 없음
- 사실: `build_system_instruction` 호출은 `main.py:866`(dev `/__dev/call-prompt`)·`scripts/dev_dump_prompt.py` 뿐
  (실통화는 C14-a 로 chat 대본, `call_session.py:3413~3599`).
- 수정(표시만, 삭제 안 함): `normal.md`·`normal.default.md` 머리말과 `docs/prompts/EDITING.md` 표에 «실통화 미사용» 명시.

## P03 — 퀴즈 개시 «먼저 말하라» vs «'퀴즈 시작' 표시 넣지 마라»
- 사실: `locked/expression.py:50` QUIZ_LINE_1 ↔ `locked/seeds.py:312` 큐 끝 문장(T17-②: 비버가 «[퀴즈 시작]» 을 대괄호째 말함).
- 수정: 큐 끝 문장을 «네 말에 대괄호를 넣지 마라 — 퀴즈를 낸다는 말은 {locale_label}로 그냥 하고 문제를 내라.» 로.
  대괄호 금지(T17 방어)는 유지, 금지 예시 리터럴 «'퀴즈 시작'» 은 제거(README 원칙 2 — 금지 예시는 씨앗).

## P07 — 재접지 쪽지가 오답 재출제를 직접 지시
- 사실: `locked/reground.py` «아직 틀린 표현 … 이 통화 안에서 한 번 더 물어 맞히게 해라» ↔ QUIZ_LINE_1 «[안내]가 알릴 때만».
  오답 재출제는 T16(09-11) 이후 서버가 연다(`call_session.py` `_arm_expression_quiz_cue(..., retry=True)`, 통화당 1회) —
  쪽지 문장은 09-10(T16 이전) 설계의 잔재. 서버 창 밖 되묻기는 판정이 안 남는다.
- 수정: 목록은 유지(압축 뒤 기억용), 지시만 «다시 묻는 건 [안내]가 알릴 때다 — 스스로 다시 묻지 마라» 로. docstring 정정.
