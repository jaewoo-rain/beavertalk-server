## 0. 한 줄

표현학습에서 어댑터·시드·격리 규율이 이미 돌고 있으니, 두 코스는 **대본 2개 + 분기 자리**
가 일의 거의 전부다. 다만 **프리토킹은 언어 규칙이 표현학습과 정반대**여서 베끼면
안 되고, **자유대화는 「기억」이라는 새 축**이 붙는다.

## 1. 지금 코드가 어떻게 돼 있나 (전부 실검증)

| 콜타입 | cur 라우트 | 엔진 | 대본 |
|---|---|---|---|
| `expression` | ✅ | **OpenAI**(env) | `core/openai/prompts/expression.py` |
| `freetalk` | ✅ | **OpenAI**(env, 2026-10-08) | `core/openai/prompts/freetalk.py` |
| `chat` | ⛔ **안 탄다** | Gemini | `core/prompts/chat.py` (129줄) |
| `level_test` | — | Gemini **고정** | `core/persona_prompt.build_leveltest_instruction` |

⇒ cur 라우트가 내는 코스는 **`expression`·`freetalk` 둘뿐**이다
(`curriculum_service` — `course = COURSE_FREETALK if status == STATUS_EXPRESSION_DONE else COURSE_EXPRESSION`).
`chat` 은 별도 콜타입(프리미엄 자유대화)이라 **다른 자리를 지난다**(`elif call_type == "chat"`).

### ⚠ 요청한 콜타입 ≠ 실제 코스
```python
call_type = cur_open.course          # 이어하기면 cur_call 의 코스가 이긴다(§7 P0)
```
데모에서 `expression` 을 골라도 그 차시의 표현학습이 끝나 있으면 서버가 **`freetalk` 을
연다.** 정본은 `call_started` 의 `course` 다. 2026-10-08 에 데모 페이지에 이 경고를 박았다.

### 두 코스가 표현학습과 다른 점
| | 표현학습 | 프리토킹 | 자유대화 |
|---|---|---|---|
| 언어 | **모국어 90%** | ⛔ **100% 학습 언어** | 100% 학습 언어 |
| 서버가 쥔 것 | 퀴즈 창·재시도·판정 | **없다** | **없다** |
| 체크판·진도 | 쓴다 | ⛔ **안 쓴다** | 안 쓴다 |
| 특수 축 | 드릴·따라 말하기 | **역할극** | **기억**(`chat_memory`) |

## 2. 비범위
- `level_test` — Gemini 고정(측정 설계가 Gemini 발화 모양에 묶여 있다).

## 3. 「잔기술」 중 빼도 되는 것과 못 빼는 것

**자동으로 꺼진다(할 일 0)** — 표현학습 전용 쪽지는 전부 `if not state.expr_items: return`
으로 시작한다. 프리토킹은 `expr_items` 가 비어 한 줄도 안 돈다. 재접지도 OpenAI 경로는
이미 off.

**⛔ 못 빼는 것 — 잔기술이 아니라 불변식**
| | 왜 |
|---|---|
| 선톡 시드 | 누군가 먼저 말해야 통화가 열린다 |
| 무음 넛지 3단 + 종료 시드 | **종료를 서버가 소유한다.** 없으면 통화가 안 끝나거나 비버가 스스로 끊는다(call 706·852·870) |
| 루프 차단 | 역할극은 장면이 멈추기 쉬워 **여기가 더 필요하다** |

셋 다 OpenAI 판이 이미 있다 ⇒ 프리토킹용으로 새로 만든 건 **선톡 시드 하나**뿐.

## 6. 자유대화(chat) — 남은 기획

- `core/openai/prompts/chat.py` 신설: 프리토킹 대본 + `[관심사]`·`[기억]` 두 블록
  (**없으면 생략** — 빈 블록이 나가면 모델이 지어낸다).
- 「아는 척」 시드는 **기억이 있을 때만**(`memory_is_substantial` 이 유일한 관문).
  ⚠ 그 시드는 `send_text_turn` 통로라 **이중발화 가드가 떨굴 수 있다.**
- ⛔ **분기 자리가 다르다** — `chat` 은 cur 라우트를 안 타므로 `elif call_type == "chat"`
  쪽에 따로 열어야 한다. 프리토킹처럼 cur 블록 안에 넣으면 **닿지 않는다.**
- 원가는 **코스마다 따로 실측**한다. 표현학습 수치($0.24~0.32/15분)를 그대로 쓰면 안 된다 —
  100% 학습 언어 + 긴 발화라 토큰 분포가 다르다.

## 7. 프리토킹 — 구현된 것 (2026-10-08)

### 대본 `core/openai/prompts/freetalk.py` (신설, 렌더 2,231자 / Gemini 3,022 대비 −26%)
블록 8개: `[절대 금지]` · `[너는 누구인가]` · `[학습자 수준]` · `[이번 상황]` ·
`[네 턴은 이렇게 닫는다]` · `[막혔을 때 — 그 턴만]` · `[틀린 말이 나왔을 때]` ·
`[학습자를 놓지 않는다]` · `[상황과 상관없는 말]`

차시 네 칸(`situation`·`partner`·`items`·`probes`)을 그대로 받고, **문형은 이름 대신
예문으로** 싣는다. ⭐ 사장님 지시로 `[이번 상황 — 이 통화의 **유일한** 소재다]` 에
「상황 밖에서 화제를 가져오지 않는다」를 박았다.

**표현학습 교훈을 원리로만 가져왔다**: ①턴을 **의문문으로** 닫는다(빈 자리를 남기지
않는다) ②금지 예시 나열 금지(씨앗이 된다) ③`[막혔을 때]` 를 **이분법**으로.

### 배선 `domains/learning/realtime/call_session.py`
`if cur_open.course == "expression": … else:` 의 **else(= 프리토킹)** 에 엔진 분기를
넣고 기존 Gemini 블록 23줄을 그 아래로 들여썼다. `use_openai` 는 `False` 기본값이 있어
길이(단일 세션)·조각 상한 1·엔진/모델이 **저절로 따라온다** — 그 자리들이 코스를 안 본다.

### 데모 `scripts/gpt_call_demo.html`
엔진 추정이 `course !== 'expression'` → 「Gemini 확실」이었다. 프리토킹 배선으로 **거짓이
됐으므로** `course ∈ {expression, freetalk}` 로 고쳤다. 「요청 ≠ 실제 코스」 경고도 추가.

### 시험 8개
격리는 `PKG.rglob("*.py")` 라 새 파일이 **import 금지 검사에 자동 포함**된다. 그 위에:
목표어 100% 선언 · 드릴/판정 어휘 0 · 종료 어휘 0 · 차시가 유일한 소재 · 시드에 소재 0 ·
게이트 · 배선 구조 · 브리프 전달.

### 켜는 법
```
EXTRA_ENV=OPENAI_REALTIME_COURSES=expression,freetalk \
  SERVICE=beavertalk-app-gpt-api bash scripts/deploy_demo.sh <태그>
```
env 를 안 바꾸면 코드만 올라가고 프리토킹은 **계속 Gemini** 로 간다(분기가 안 돈다).
