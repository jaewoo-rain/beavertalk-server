# 프롬프트 DB override — 배포 없이 대본을 고친다 (2026-10-10)

## 왜 (사장님)

> 「한 줄 바꿀 때마다 다시 빌드하는건 너무 비효율적이라고 생각이들어서」

실제 비용: **빌드+배포 5~8분.** 오늘 대본 한 줄을 네 번 고쳤고 그만큼 기다렸다.
env 변경은 빌드가 없어 ~1분, DB 는 초 단위다.

## 이 레포는 이미 반쯤 만들어 뒀다

`core/prompts/editable_loader.py`(2026-09-12 「잠금/편집 분리」)가 같은 발상이다 —
`editable/*.md` 를 읽고 **다섯 가지 검사**를 돌리고, 어기면 `.default.md` 로 폴백하고
ERROR 를 남긴다. 빠진 것은 하나뿐이다: **저장소가 이미지 안의 파일이라 배포가 필요하다.**
⇒ 새로 만드는 일이 아니라 **출처를 DB 로 더하는 일**이다.

## ⛔ 공통 스키마는 없다 — 그리고 없어도 된다

측정값(2026-10-10):

| 대본 | 슬롯 | 대괄호 라벨 |
|---|---|---|
| expression | `l` `t` `g` | `[오늘의 표현]` |
| freetalk | (위치 인자 `%s`) | `[이번 차시]` |
| chat | (시드만 `{topic}`) | `[관심사]` `[기억 …]` |
| leveltest | `role` `personality` `locale_label` `target` `username` `interests_text` `ladder` | 여러 개 |

**네 대본이 다 쓰는 슬롯 0개, 라벨 0개.** 표기법조차 셋이 다르다.
⇒ 검사는 **「그 대본 vs 그 대본의 코드 기본값」**이다. 대본끼리 비교하지 않는다.
공통이 없다는 것이 오히려 안전하다 — 하나를 고쳐도 다른 셋을 깨뜨릴 길이 없다.

## 설계

### 무엇을 덮어쓰나 — **대본 글자만**. 데이터 블록은 코드가 계속 만든다

```
지금 : [# 역할][# 시작][# 연습][# 진행] + [오늘의 표현](코드 생성) + [표정](선택)
override:  ←───────── 이 넷만 교체 ─────────→   + 그대로              + 그대로
```

⭐ 이게 **라벨·데이터 짝을 자동으로 지킨다.** 대본이 `[오늘의 표현]` 을 이름으로 가리키고
그 블록은 코드가 만드므로, 사장님이 대본에서 라벨을 바꾸면 검사 ②가 잡는다.

### 층 분리 — 격리 규칙 때문에

```
domains/learning/models/prompt_override.py        테이블(append-only)
domains/learning/repository/…_repository.py       active_body(db, name) → str | None
core/openai/prompts/override.py                   vet(name, body, default) → (ok, reason)  ⛔ DB 모름
core/openai/prompts/<name>.py                     build_…(…, script_override=None)
domains/learning/realtime/call_session.py         DB 읽기 → vet → 통과면 넘김, 아니면 코드 기본값
```

⛔ `core/openai/` 는 `domains.`·`db.` 를 import 할 수 없다(`test_openai_isolation.py` 가
AST 로 전수 검사). 그래서 **DB 읽기는 서비스층, 검사는 어댑터의 순수 함수**로 가른다.

### 검사 네 가지 (어기면 코드 기본값 + ERROR 로그)

1. **슬롯 집합이 기본값과 같다** — `{locale_label}` 오타 하나가 통화를 못 열게 만든다
2. **대괄호 라벨을 새로 만들 수 없다** — 대본이 없는 블록을 가리키면 데이터가 안 붙는다
3. **금지어 수가 기본값을 넘지 않는다** — 종료 어휘(call 706·852·870 이 자력 종료로 끝났다)
4. **길이 상한** — 원가가 곧 입력 토큰이다

### 안전장치

- **env 스위치** `PROMPT_OVERRIDE_ENABLED` **기본 꺼짐.** 켜지 않으면 바이트 무영향이다.
- **통화 시작에 스냅샷.** 한 통화 중간에 글자가 바뀌지 않는다.
- **`call` 행에 쓴 override id 를 적는다.** 오늘 1815 와 1817 을 *Cloud Run 리비전*으로
  갈랐는데, 그때부터는 id 로 가른다 — 전사 분석에 반드시 필요하다.
- **append-only.** 덮어쓰지 않고 행을 쌓는다(`enabled` 로 현역을 가린다). git 이력을
  잃는 대신 테이블이 이력을 든다.
- **코드 기본값을 지우지 않는다.** ①망가졌을 때 돌아갈 자리 ②시험이 계속 지킬 대상.

## 「테이블 추가가 다른 데 영향 없나」 (사장님 질문)

**없다.** 근거:

- 새 테이블은 기존 읽기·쓰기 경로를 건드리지 않는다. `voice.openai_name` 과 같은 성질이다.
- ⚠ 다만 이 DB 는 **실서비스와 공유**다(`app-api`·`demo-api`·`gpt-api` 가 같은 Supabase).
  그래서 **코드 쪽 스위치가 기본 꺼짐**이어야 한다 — 이 브랜치가 언젠가 머지돼도
  스위치를 안 켜면 실서비스는 종전 그대로다.
- ⚠ `alembic revision --autogenerate` 는 이 레포에서 **안 돈다**(`DATABASE_URL_DIRECT` 가
  설정돼 있지 않아 6543 pgbouncer 로 붙고 `json = unknown` 으로 깨진다). 마이그레이션은
  **손으로 쓴다** — `c1d2e3f40506`(voice.openai_name)도 그렇게 했다.

### 편집 경로 — `scripts/dev_prompt_override.py`

생 SQL 을 치지 않게 스크립트로 고정했다. 핵심은 **`put` 이 `vet` 을 먼저 돌리고, 거부되면
아무것도 쓰지 않는다**는 것이다.

```
status                      현역 행 + 스위치 + 대상 DB + override 로 돌은 통화 수
dump  <이름> --out 파일      현역(없으면 코드 기본값) 글자를 **그대로** 뽑는다
check <이름> --file 파일     검사만(DB 안 건드림)
put   <이름> --file 파일     통과 시 새 행 + 현역 세움(이전 현역 자동 내림)
off   <이름>                 현역을 내려 코드 기본값으로 복귀(행은 남는다)
```

손시험: `dump` → 글자 수정 → `check` **통과**(513자) / `[새 블록]` 추가 → **거부**
(「기본값에 없는 대괄호 라벨 ['새 블록']」) / `dump` → 손 안 대고 `check` → **508자 그대로**.

⚠ 마지막 것이 처음엔 509자였다 — `dump` 가 끝에 줄바꿈을 덧붙였다. 편집기도 꼬리 줄바꿈을
넣으므로 **읽는 쪽에서 기본값 모양에 맞춰 깎는다**(`_read_body`). 안 그러면 대본이 왕복마다
1자씩 자란다.

## 편집 화면 `/__devprompt` (2026-10-10 2차 — 사장님 지시 「DB 편집할 수 있는 사이트」)

`scripts/prompt_editor.html` + `/__dev/prompts*`. 기존 dev 콘솔(`/__devgpt`·`/__levelcalldemo`)
과 **같은 관례**를 따른다: `DEV_ROUTES_ENABLED` 게이트 + `CurrentAdmin` + `include_in_schema=False`
+ 토큰은 이 페이지를 준 서버가 준다(`/__dev/login` — Supabase 주소·키를 페이지에 박지 않는다).

### 화면의 순서가 설계다

```
[불러오기] → 고친다 → [검사·미리보기] → [올리기(현역)]
                           ↑ 통과해야 「올리기」가 열린다. 글자를 고치면 다시 잠긴다.
```

⭐ **미리보기가 이 화면의 핵심이다.** 가짜 표현 3개로 **끝까지 조립**해 보여준다 — 슬롯이
값으로 채워진 모습과, 코드가 붙이는 `[오늘의 표현]` 블록이 **어디에 붙나**까지. 글자만 보고
올리면 「대본은 그럴듯한데 데이터가 안 붙는」 사고를 못 잡는다.

⛔ **검사를 건너뛰는 버튼은 두지 않았다.** 화면에서 잠그고, 서버가 `put` 에서 **다시** 검사한다
(화면을 우회해도 막힌다). 거부되면 **행이 생기지 않는다** — 시험이 그걸 못박는다.
