## 1. 하네스가 하는 것 (①~⑦ 전부 구현)
```
--fix-items   레벨 1 고정(upsert_language_level) + FIXED 밖 28개 quiz_passed_at 찍음 → 선별 풀 18 고정   (1회)
--reset       18개 drilled_at/drilled_call_id/quiz_passed_at NULL (--runs 가 매 회 자동)
--probe       연결 → 첫 비버 턴 → 항목 매칭 보고 끊음
--runs N      reset → WS 통화(call_type=expression, duration_min) → 채점 → docs/e2e 보고서 · exit 1 = 불일치
--logs        gcloud logging read 로 판정 계측·arm·마지막 판정 ms 첨부
```
듣기: turn_end 마다 «따옴표 안 영어 뜻 → 여러 단어 구절 → 키워드(질문 턴만) → LLM 1회» 로 항목 식별. 앵커(quiz/review/…)·공개(표면형)·
되감기(끝낸 항목 재질문 = 앵커 없는 회차)·거짓 칭찬(오답 다음 턴의 **반응 문장**만 대조)·대괄호 누출·STT(input_transcript) 를 턴마다 기록.
말하기: 대본 정책(드릴 순번 k → (k-1)%6+1) → TTS LINEAR16/16k → 0.8초 뒤 40ms 프레임 실시간 페이싱, 뒤 무음 1.2초, 다음 turn_start 까지 무음 프레임.
기대치: `drilled` = 표면형이 실제 한 번 나옴(비버 공개 또는 학습자 발화) · `passed` = 퀴즈 회차에서 공개 전 자발 정답. 앵커 없는 회차에서만 난 정답은 `passed~`(어느 쪽이든 허용).
