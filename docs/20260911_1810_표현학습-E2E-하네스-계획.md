## 1. 고정 18개 (L1 46 중) — `--fix-items` 가 나머지 28개에 `quiz_passed_at` 을 찍는다

선정 기준: 뜻이 영어 한 구절로 또렷하고 서로 안 겹치는 것. 제외 — `◯◯` 자리표시(11118·11119·11135),
숫자 청크(11138~11141), 1~2음절 단답(네·아니요·아니에요), 「몰라요」(학습자 대본 «I don't know» 와 충돌),
뜻이 겹치는 쌍의 한쪽(고마워요/감사합니다 · 미안해요/죄송합니다 · 안녕히 가세요/계세요 · 천천히/다시 말해 주세요 · 이해 못 했어요/잘 못 들었어요).

```
11096 안녕하세요?        11097 만나서 반갑습니다   11098 잘 지냈어요?       11102 좋은 하루 보내세요
11104 감사합니다         11107 죄송합니다          11109 괜찮아요           11116 진짜요?
11117 맛있어요           11120 이름이 뭐예요?      11122 잘 부탁드립니다    11123 이거 주세요
11124 얼마예요?          11125 화장실이 어디예요?  11126 도와주세요         11127 여기요!
11129 배고파요           11133 잘 못 들었어요
```
반말 함정(대본 3)용 반말형은 **손으로 쓴 표** 로 둔다(«끝 요 제거» 는 감사합니다·이거 주세요 등에서 틀린 형이 나온다).
드릴 오답(대본 4·5)의 미끼는 **제외된 28개의 표면형**(고마워요·미안해요·좋아요·맞아요…)을 쓴다 — 판정기 후보 목록 밖이라
오검출로 다른 항목이 통과 처리될 길이 없다.

## 2. 상태기계 (turn_end 마다)

```
mode ∈ {drill, quiz}   current_item   drilled_order[]   per-item 기록
① 앵커     quiz/review/remember/test/recap/see if you … 뜻     → mode=quiz, anchor_at=len(drilled_order) 기록 ⭐
② 공개     18개 표면형 중 하나가 턴에 있다 (정규화 부분일치)     → 그 항목 reveal (학습자가 방금 정답을 낸 뒤의 에코는 제외)
③ 항목식별 en 뜻·키워드 대조(모드별 후보 제한) → 실패 시 generate_structured 1회(번호 또는 0) → 그래도 0 이면 «현 항목 계속»
   drill 후보 = 미드릴 항목(+현 항목) / quiz 후보 = 드릴됐고 이 회차 미출제(+이전 오답)
   quiz 모드에서 미드릴 항목이 잡히면 → mode=drill (퀴즈 끝)
④ 대본     drilled_order 에서 현 항목의 번호 k → (k-1)%6+1 정책이 이번 답을 정한다
⑤ 기대치   판정기 규칙 그대로 하네스가 계산: passed ⇔ quiz 모드 · 그 회차 공개 전 · 학습자가 «자발 정답»(하네스가 고른 것)
           → 대본 1·6 = passed, 2 = failed, 3 = not passed, 4 = drilled only, 5 = 공개 없이 힌트만 받았으면 passed
```

## 3. 채점 축 (call_ended 뒤 · DB + 전사)

모국어 선질문(새 항목 첫 턴에 표면형 없음) · 거짓 칭찬(대본상 오답 다음 비버 턴의 칭찬 어휘 − 교정 어휘) · 자발 산출 수 ·
`[Country]` 대괄호 · 되감기(완료 항목 재소개) · 앵커 없는 퀴즈 · STT(input_transcript ↔ 보낸 문장) · (선택 `--logs`) 마지막 판정 ms · arm.
