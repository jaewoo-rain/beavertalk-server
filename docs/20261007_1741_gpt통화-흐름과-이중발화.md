## 2. 이중발화 — 실체와 원인

### 증거 (call 1760)
```
15:30:30.305  "... in Korean now."              ← 1차 끝
15:30:30.443  "Sure"                            ← 138ms 뒤 2차 시작, turn_id 동일
BEAVER[t13] 읽기=16.0자per초 [en:147자/9.2초]   ← 정상 턴의 2배
```
같은 지시를 두 번 말했다. 그리고 **`시드 생략` 0건** — 우리 코드는 `response.create` 를
한 번도 더 쏘지 않았다.

### 원인 (call 1764 로 확정)
```
⛔interrupted #1 · #2: 모델이 자기 턴을 버렸다
🔬 오디오 공백 1.21s · 2.72s · 1.55s · 3.41s
응답지연 … 5.26초 … 19.86초
비버 문장이 「Try again and say this:」 에서 **잘렸다**
```
`interrupted` = 벤더가 `response.status=cancelled` 를 보낸 것(`core/openai/session.py`).
TPM 은 여유였다(`194,798/200,000`).

**`turn_detection.interrupt_response` 의 기본값이 `true`** 다. 우리는 barge-in **off**
설계인데 벤더만 「유저 소리가 들어오면 비버 턴을 끊는다」로 돌고 있었다.

관문이 **셋**인데 하나가 비어 있었다:

| 층 | 어떻게 막나 | 상태 |
|---|---|---|
| 서버 | `if data and state.turn_id is None` (`call_session.py`) | 있었다 |
| 클라 | `_micGated` — 재생 큐 비움 + 행오버 (`normalcall_controller.dart:1500`·`:4783`) | 있었다 |
| **벤더** | `interrupt_response` | ⛔ **비어 있었다** |

서버·클라 두 관문이 있어도 **`turn_start`(첫 자막)와 실제 오디오 재생 시작 사이**로
프레임이 샜고, 그게 벤더 쪽에서 턴을 끊었다.

### 고친 것
```python
TURN_DETECTION: dict = {"type": "semantic_vad", "interrupt_response": False}
```
⛔ `create_response` 는 **건드리지 않았다.** 그건 끼어들기 축이 아니라 「누가 응답을
만드나」 축이고, `false` 로 하면 커밋마다 우리가 직접 만들어야 해서 한 번 놓치면 통화가
벙어리가 된다(R5). 시험: `test_turn_detection_disables_vendor_barge_in`.

### 같이 남겨 둔 가드
`send_text_turn` 이 응답 진행 중이면 **아무것도 안 한다**(항목도 안 넣는다).
⚠ 1757~1766 에서 **한 번도 발동하지 않았다**. 실재하는 실패 모드를 막는 방어지만
**관측된 사고의 원인은 아니었다.**

## 3. 입력 전사 결함 2개

### ① 전사가 정확히 2배 — 고쳤다
```
👤 user: I / don't / know / that / .      ← 델타
👤 user: I don't know that.               ← completed(전문)
USER[t2]: I don't know that.I don't know that.
```
벤더가 델타와 `completed` 를 **둘 다** 주고 `completed.transcript` 는 그 턴의 **전문**이다.
호출부는 받은 조각을 전부 `cur_user_text` 에 쌓아 `"".join` 한다 ⇒ 2배.

⚠ **처음엔 델타를 끊어서 고쳤다가 되돌렸다.** 그러면 중복은 사라지지만 학습자 자막이
문장 끝에야 떠서 **체감이 느려진다**(사장님이 call 1764 에서 바로 잡아냈다).
⇒ **흘리는 쪽(델타)을 남기고 합계(`completed`)를 버린다.** 델타의 합이 곧 전문이다.

⚠ 그래서 이 경로에선 `is_final=True` 가 **영영 안 온다.** 지금 호출부는
`REGROUND_ATTACH_AT in ("first","final")` 에서만 그 값을 보고 운영은 `mic_open` 이라
안 탄다. **그 env 를 바꾸려면 어댑터도 같이 본다.**

### ② 빈 전사로 사용자 말이 유실된다 — **미해결**
```
OpenAI 입력 전사 확정이 비었다(무음 워처에 맡긴다)
USER[t4]: (무음/전사없음)        ← 오디오는 실재: 0002_user.mp3 228KB
```
사용자가 말했고 **오디오는 올라갔는데** 전사만 비었다. 서버는 무음으로 기록하고
OpenAI 는 소리를 들었으니 응답했다 ⇒ **자기 말이 씹힌 채 비버가 계속 말하는 것**이 된다.

`OPENAI_REALTIME_TRANSCRIBE_MODEL = "gpt-4o-mini-transcribe"` 는 `core/config.py` 가
**미검증**이라고 못박아 둔 모델이다. 다음 수는 `whisper-1` — **env 한 줄, 코드 0줄.**
⚠ Gemini 는 `AudioTranscriptionConfig()`(모델 이름 없음)라 이 지렛대가 **없다** —
OpenAI 만 입력 전사를 별도 모델이 돌린다.

## 4. 진행 흐름 재설계 (codex 안 · 검증 완료)

### 무너진 자리
항목표에 **숫자·목록형**이 섞여 있다:
```
1=하나·둘·셋·넷·다섯   2=여섯~열   3=일~십   12=한 개 주세요·두 개 주세요
```
옛 틀은 모든 항목에 「언제 쓰는지 **상황**을 하나 준다」를 요구했다. 숫자엔 상황이 없다
⇒ 모델이 억지를 만들었다: 1760 B1 `"counting a sequence for scheduling"`.

### 결론: 종류를 판별하지 않는다. 「뜻」으로 묻는다
숫자 항목의 `des` 에 범위가 **이미 있다**
(`assets/level/curriculum_v2/survival_chunks.json:342-370` — `"1–5 (native)"` 등).
⇒ 상황을 발명할 필요가 **없었다.**

분기 **5 → 4**, 출제 2문장 → **1문장**, 오답 3문장 → **2문장**.
재시도 횟수·퀴즈 시점을 블록에서 **뺐다**(서버 소유라).

⚠ **원본 데이터엔 `category: "숫자"` 와 `situation` 이 있다.** 프롬프트에 오는 DTO 가
`{item_id, obj, des, ex}` 라 안 보일 뿐(`normalcall_service.py:394-425`). 서버가 실어
주면 **종류 분기·상황 틀 유지도 가능하다** — 선택지가 남아 있다.

### 같이 바꾼 것 — 덮어쓰기 제거
동적 퀴즈 쪽지가 `각 문제는 {모국어} 로 **뜻과 상황만** 주고…` 였다
(`core/openai/prompts/seeds.py:168`). 그대로 두면 **뒤에서 새 틀을 덮어쓴다.**
`각 문제도 [진행] 틀로 묻는다.` 로 **일대일 치환**했다.

## 5. Fable 2라운드 — 선공개는 「판단」이 아니라 **「완성」**이다

1라운드(오답 이분법 + 순서 뒤집기)로 A·B·C 가 잡혔다. 그런데 **선공개가 3건 재발**했다.

```
B3  ... Now listen and repeat after me: 물 주세요.
B5  ... Now say in Korean:               여기요!      ← 그 꼴을 베꼈다
```
선공개 3건이 전부 **오답 턴 3연속 직후**였다. **빈 자리를 남기고 끝나는 명령문**
(`say it in Korean:`)이 그 자리를 정답으로 채우게 한다 — 옛 틀에선 C(정답 두 번)로,
새 틀에선 선공개로 나왔다. **같은 뿌리다.**

⛔ 세션 맨 앞의 `[절대 금지] 1` 은 **최근 3턴의 템플릿 완성에 개입할 자리가 없다.**

⇒ 2라운드 처방: 출제 턴을 **「뜻이 맨 뒤에 오는 의문문」**으로 고정. 의문문은 `?` 로 닫혀
빈 자리가 없고 맨 뒤를 영어 뜻이 차지한다. 오답 턴(서술문+한국어 맨 뒤)과 **서로소**가 된다.

⚠ 그리고 1760·1764 의 선공개 0% 가 **다시 해석된다** — 그때 오답 틀이 「한국어 → 영어」
순서라 **베낄 꼴이 이력에 없었다.** `[절대 금지] 1` 덕이 아니었을 수 있다.
