# 캐릭터 추가 체크리스트 (R7 · PM-DEC-673 · 2026-10-16)

- 캐릭터 소개(description)·스토리(story) 다국어는 서버 칸이 아니다.
- 앱 `lib/features/character/data/character_copy_overrides.dart` 사본이 29개 언어로 덮는다(현재 character_id 1·2·9·10·11).
- 사본에 없는 캐릭터는 한국어 원문이 그대로 보인다.

## 새 캐릭터를 운영에 넣을 때

- [ ] `character` 행 추가 전에 소개·스토리 한국어 원문을 확정한다.
- [ ] 같은 문구의 29개 언어 번역을 준비한다(AI 번역이면 표기).
- [ ] 앱 `character_copy_overrides.dart` 에 새 character_id 항목을 추가한다.
- [ ] 앱 빌드가 배포된 뒤에 서버에 캐릭터를 연다(순서가 바뀌면 한국어 노출).
- [ ] 옛 앱 사용자는 한국어로 보인다 — 공지 필요 여부를 PM 에 묻는다.

## 범위

- 서버 번역 칸 신설(`character_i18n`)은 이번에 하지 않는다(요청서 R7 (b) · 선택).
