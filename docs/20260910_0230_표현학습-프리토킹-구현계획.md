### ⭐ 구현 중 발견 — 규칙 5·6 도 같이 옮겨야 했다 (계획보다 넓어졌다)
처음엔 규칙 7(`RULE_OFF_TOPIC`)만 옮길 생각이었는데, 새 코스에서 그 규칙을 5번으로 다시
번호 매기려다 **끊긴 참조**가 될 뻔했다:

```
규칙 6 본문 : "… 할 말의 분량은 **규칙 5** 그대로다."
규칙 7 본문 : "… 설명이 길어지면 그 자체가 **규칙 5** 위반이다."
```
⇒ 두 규칙이 **번호로 규칙 5를 인용한다.** 새 코스에서 번호를 다시 매기면 모델이 가리키는
곳을 못 찾고, 그러면 규칙을 따르는 대신 **자기 마음대로 채운다**(2026-08-19 에 정확히 그
계열로 2건을 고쳤다 — README §8).

**결정: 새 코스도 규칙 번호를 5·6·7 그대로 쓴다.** 그래서 규칙 5·6 도 `common` 이 소유하고,
표현학습·프리토킹은 1~4 만 자기 것으로 쓴다. ⇒ 인용이 통째로 살아 있다.
⚠ `DEFAULT_MAX_SENTENCES`(=4)도 같이 옮겼다 — 규칙 5 문구의 숫자가 두 곳에 손으로 적히면
안 된다(원칙 3). `RULE_OFF_TOPIC_BODY`(번호 뗀 본문)도 만들어 뒀지만 **아무도 안 쓴다**
(번호 유지가 원칙이라, 정말 필요할 때를 위한 탈출구로만 둔다).

`RULE_OFF_TOPIC` 은 지금 템플릿 문자열 **안에** 박혀 있다. `_RULE1_MODE_DEFAULT` 를 뽑아낸
선례(`persona_prompt.py:197`)와 **똑같은 방식**으로 상수 + 문자열 이어붙이기로 뺀다 —
재배치일 뿐이라 출력 바이트가 안 변한다.

### `persona_prompt.py` 변경
- 위 심볼을 `from core.prompts.common import ...` 로 받고 **같은 이름으로 재수출**한다.
  (`call_session`·테스트·데모가 `persona_prompt.CONTROL_TAG` 를 그대로 import 한다 —
  `call_session.py` 만 6곳. 이름을 안 바꿔야 그 전부가 무손상이다.)
- `_RULE_CLOSE_PROTOCOL = RULE_CLOSE_PROTOCOL` · `_INVARIANTS_TEMPLATE` 조립에
  `RULE_OFF_TOPIC` 을 이어 붙인다. **그 외 한 글자도 안 건드린다.**

### 잠금
- `tests/test_prompt_common_snapshot.py` 신설: `build_system_instruction` 3조합
  (기본 / 체크판 / 캐스케이드 옵트인)의 출력이 **T1 전과 바이트 동일**임을 sha256 로 못박는다.
  ⭐ 기준값은 T1 착수 **전에** 현재 코드로 뽑아 파일에 박는다(스냅샷 규율 — 나중에 뽑으면 무의미).
- 기존 `tests/test_persona_prompt.py` 의 동결본(`_ORIG_*`)은 **손대지 않는다.**
  거기가 깨지면 내가 공용 자산을 건드린 것이다.

## 9. T9 — 조각 경계 진도 승계

### ⛔⛔ 9-A. 정정 — «같은 18개» 가 아니다 (2026-09-10, codex QA)
기획서 §2-7 초안과 이 계획서 §5 초안은 *"조각2 지시문에 18개 전부 + 1~7 은 통과"* 라고
적었는데 **거짓이었다.** 조각2는 **새 WebSocket = 새 `_CallState`** 라 선별이 다시 돌고,
선별이 `random()` 이라 **목록도 번호도 조각1과 같지 않다.**
목록을 고정하려면 코호트를 저장해야 하는데 테이블이 하나 더 늘고 «매번 랜덤» 과 충돌한다.
⇒ **고정하지 않기로 결정**(사장님·bt-back). 연속성은 **선별 정렬**이 만든다:
`quiz_passed_at IS NULL` 이 통과분을 풀에서 빼고, `ORDER BY (drilled_at IS NULL)` 이
조각1에서 드릴한 미완을 앞으로 올린다. «같은 목록» 이 아니라 **«같은 진도»** 가 이어진다.

⇒ 그래서 지시문 문구는 번호가 아니라 **표식**으로 말한다:

⛔  "1~7 은 통과했다. 8번부터 시작하라."     ← 목록이 매번 달라지므로 거짓말이 된다

`skip_mastery = call_type != "normal"` 로 위 3개를 감싼다.
⛔ `normal` 의 동작은 한 줄도 안 바뀐다(기본값이 `"normal"`). 회귀가 그걸 지킨다.
