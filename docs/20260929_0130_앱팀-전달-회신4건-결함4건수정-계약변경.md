### 2-4. §26-④ 알람 발송 루프 `db.rollback()` 누락

요청대로 건별 `except` 에 `rollback()` 을 넣었습니다. **그런데 더 나쁜 경로가 같이 있었습니다:**

flush 실패(예: 토큰 무효화 커밋)가 나면 SQLAlchemy 가 세션 객체를 전부 만료시키고, `try` **밖**에 있던 `a.time` 읽기가 `PendingRollbackError` 로 터져 **디스패치 전체가 500** 이 됐습니다. 요청서의 「그 분 나머지 알람 건너뜀」보다 큰 범위입니다. 수정 전 코드로 재현해 확인한 뒤 `a.time` 읽기를 `try` 안으로 옮겼습니다.

확인한 것: `rollback` 이 **이미 발송된 다른 알람의 기록을 되돌리지 않습니다** — `_claim` 이 INSERT 직후 그 자리에서 commit 하고 `_ring` 도 자기 commit 으로 닫혀서, 알람 사이에 미커밋 쓰기가 없습니다.

## 3. ⚠ 계약 변경 2건 — 빌드 45 전에 확인해 주세요

### 3-1. 잘못된 `tz` 는 이제 **422** 입니다 (200 아님)

`POST/PUT /alarms` 의 `tz` 를 요청 경계에서 IANA 로 검증합니다. 판정은 디스패치와 **같은 함수**를 씁니다(두 곳이 갈리면 「저장은 됐는데 디스패치가 폴백」이 또 생깁니다).

| 보낸 값 | 결과 |
|---|---|
| 유효한 IANA (`America/New_York`) | ✅ 200, 정규 이름으로 저장 |
| 잘못된 값 (`GMT+09:00`, 오타 등) | ⛔ **422** |
| 미지정 · 빈 문자열 · 공백만 | ✅ 200 — 미지정으로 다룸(생성 시 NULL, 수정 시 기존 값 유지) |

⚠ **기기가 내주는 값이 IANA 가 아닐 수 있는 경로를 확인해 주세요.** 구형 안드로이드에서 `GMT+09:00` 같은 문자열이 나오는 경우가 있습니다 — 그걸 그대로 싣으면 알람 저장이 실패합니다.

왜 막았나: 전에는 잘못된 값이 **200 으로 저장**되고, 디스패치가 경고 후 폴백하는 동안 그 회원은 엉뚱한 시각에 전화를 받았습니다. 앱도 사용자도 모릅니다. §25-① 에서 `tz_offset_min` 범위는 막았는데 `tz` 만 빠져 있었습니다.

### §22-③ 복원 건별 사유 — 쓸 수 있습니다

`POST /purchases/restore` 응답에 **`items`** 가 추가됐습니다(`restored`·`failed` 는 그대로 유지 — 추가만).

`items[] = { product_id, result }`, `result` 는 요청서 5종 그대로:
`granted` · `already` · `owned_by_other` · `invalid` · `unavailable`.

⚠ 한 가지 매핑을 알려 드립니다: **404 `UNKNOWN_PRODUCT`**(서버 카탈로그가 모르는 상품 id)는 `invalid` 로 내보냅니다. 6번째 값을 만들면 앱 enum 을 벗어나 파싱이 깨지고, 앱 입장에선 둘 다 「재시도해도 소용없음」이라 실질이 같습니다. 서버는 그 경우 **별도 경고 로그**를 남겨 카탈로그 구멍을 스스로 발견합니다 — 오늘 `bt_character_bundle` 404 가 정확히 그 경우였고, 앱팀 보고 전까지 서버가 몰랐습니다.

### §22-⑥ 결제 내역 — 「이번 달 결제 $0」 원인 해소

스토어 결제(구독·캐릭터·묶음)가 이제 `payment` 행을 남깁니다. 추가된 값: 현지 통화 · 현지 금액(micros) · 스토어 주문 ID.

⚠ **Google 캐릭터·묶음은 가격이 항상 비어 있습니다.** `purchases.products.get` 의 `ProductPurchase` 에 **가격 필드가 원천에 없습니다**(공식 필드 목록 확인 — `orderId` 는 있습니다). 구독(`subscriptionsv2`)과 Apple(JWS)은 가격이 옵니다. 서버 버그가 아니니 그렇게 표시해 주세요.

샌드박스·스텁 결제는 **저장은 되고 월 합계에서만 빠집니다**(목록에는 나옵니다) — `iap_receipt` 와 같은 규율입니다.

### §23 무효 사유 로그

`invalid` 판정마다 **왜**를 남깁니다: 스토어 HTTP 상태 · `subscriptionState` · 요청 vs 응답 `productId` · `basePlanId`(Apple 은 `subscriptionGroupIdentifier`). Google 의 400/404(토큰 조회 실패)일 때는 스토어 카탈로그를 조회해(1시간 캐시) 「상품이 스토어에 없다」와 「토큰이 무효」를 구분합니다.

⚠ Apple 카탈로그 조회는 넣지 않았습니다 — App Store Connect API 는 별개 자격증명이고(현재 키는 App Store **Server** API 용) 실측을 못 해서 추측으로 붙이지 않았습니다.

`purchase_token` 은 어떤 로그에도 찍히지 않습니다(정적 스캔 시험이 지킵니다).

## 5. 새 기능 — 앱이 알아야 할 것

### 5-1. 무료 캐릭터는 이제 **처음부터 보유**입니다

가격 0원 캐릭터(Baba · Bibi)는 **행을 만들지 않고 파생 계산**으로 항상 보유·해금입니다. `/characters` 의 `is_owned` · `is_unlocked` 가 `true` 로 옵니다.

⭐ **덤으로 버그 하나가 사라졌습니다:** 전에는 Bibi 를 **고르기만 하고 「받기」를 안 누르면** 소유가 없어서 통화 시작 때 조용히 가장 싼 캐릭터(Baba)로 바뀌었습니다. 이제 Bibi 를 고르면 Bibi 로 통화합니다.

또 **가입 때 만들던 Baba 소유 행도 없앴습니다.** 그게 `restoreOutcomeOf` 에서 「모든 Free 계정이 캐릭터 보유로 읽혀 거절된 복원이 성공으로 보이던」 QA F003 의 근원이었습니다. 이제 `owned_character_ids` 는 **실제로 취득한 것만** 담습니다.

⇒ `owned_character_ids` 에 **무료 캐릭터는 넣지 않습니다**(현행 유지). 앱이 잠금을 `/characters` 로 그리고 있어서 영향 없습니다.

### 5-2. §6 차시 제목 · §10 통화 제목 다국어

| 위치 | 필드 | 동작 |
|---|---|---|
| `GET /cur/me` | `lesson.situation_translation` (`Optional[str]`) | 회원 `member.language` 로 고름. 한국어 회원·번역 없음 → `null`(앱은 한국어 원문만 표시) |
| `GET /calls` | `summary` | 회원 현재 언어와 생성 언어가 다르면 **번역본**을 내려줍니다 |

- 요청에 언어를 싣지 않습니다 — 서버가 `member.language` 로 고릅니다(취약 발음 설명과 같은 방식)
- 원문(`situation` · `summary`)은 바뀌지 않습니다
- 미리 전량 번역하지 않고 **요청된 (항목, 언어)만 번역·캐시**합니다 ⇒ 첫 조회가 번역 시간만큼 느릴 수 있습니다(상한 6초, 실패 시 원문)
- 목록은 한 페이지 분량만 번역합니다
- 상세(`GET /calls/{id}`)·`/cur/lessons` 는 이번 범위 밖입니다

### 5-3. ⭐ 알람 시간대 자동 추적 — 재전송이 **선택**이 됐습니다

앱이 **이미 보내고 있는** `tz` 를 서버가 회원에 기억합니다:

- `GET /calls/daily-status?tz=`
- `GET /stats/calendar?tz=`
- 통화 시작 WS `start.tz`

디스패치 시간대 우선순위: **`member.tz`(최근 기기) → `alarm.tz`(만들 때) → `tz_offset_min` → `Asia/Seoul`**.

⇒ 회원이 **앱을 한 번 열면** 그 순간 기억되고, **여행 가면 현지 시각으로 따라갑니다.** 위치 권한 불필요.
⇒ 그래서 「빈 `tz` 재전송」은 **해도 되고 안 해도 됩니다.** 앱을 안 여는 회원에게만 의미가 있습니다(해로울 것은 없습니다).

알려진 동작 하나: 배포 당일 외국 회원 알람이 먼저 서울 시각에 한 번 울리고 그 통화로 `member.tz` 가 적히면, 같은 날 현지 시각 울림은 같은 멱등 키라 1회 누락됩니다(다음날부터 정상). 대안은 그날 두 번 울리는 것이라 이쪽을 택했습니다.

⛔ 봄 서머타임 건너뜀(그 지역 로컬 02:30 이 없는 날 → 그날 안 울림)은 확정된 결정입니다. 앱팀 수용 확인했습니다.
