## 1. 한 장 그림
```
cur_topic(65) ─┐                        cur_function(30)
               ├─< cur_lesson(488 + 레벨1 생존회화 3) >─ cur_lesson_function
cur_item(11,144 = 어휘 10,636 + 문법 462 + 청크 46) >─ cur_lesson_item(11,261 + 46)  [role: grammar|must|core|support|chunk]

member ─< cur_member_progress(1행/회원: 지금 차시 포인터)
       ─< cur_member_lesson(회원×차시: 표현학습 끝·프리토킹 끝)
       ─< cur_member_item(회원×항목: 드릴·퀴즈 기록)
call   ─< cur_call(통화×차시: 어느 코스·무엇을 다뤘나·결과 스냅샷)
```

## 3. 통화가 읽고 쓰는 것 — cur_* + member 만
```
표현학습 시작   cur_member_progress(회원) → lesson_id
               cur_lesson_item ⋈ cur_item (그 차시 항목, seq 순) − cur_member_item.drilled_at IS NOT NULL
               → 남은 것 앞에서 EXPR_ITEMS_PER_CALL(18)개 = 이번 통화 재료 (문법·필수·핵심·지원 순)
               ⚠ 차시당 평균 23·최대 43 이라 353/488 차시가 2~3통화 — 남은 것부터 이어 가르친다
표현학습 판정   지금 T16 서버 판정 그대로(큐·창·V1~V4·STT 폴백) → cur_member_item(drilled_at·quiz_passed_at·quiz_failed_count) · cur_call.items
표현학습 끝     그 차시 항목 전부 drilled → cur_member_lesson.status=expression_done (퀴즈 정오 무관, 결정 #4)
프리토킹 시작   cur_member_progress.lesson_id 의 status 가 expression_done 이어야 열림
               재료 = situation · partner(상황 묘사) · 그 차시 항목 표면형 목록(써 보게 유도용) · probes — 판정 없음
프리토킹 끝     status=freetalk_done · cur_member_progress.lesson_id = 다음 no · level_no 갱신
레벨            회원 레벨 = cur_member_progress.level_no (= 지금 차시의 레벨). 마이페이지는 이것을 보여준다
```
- 옛 표현학습 선별(`pick_expression_items` — learning_item·quiz_passed_at IS NULL·random)은 **새 경로에서 안 부른다**. 랜덤 없음 — 차시 순서가 순서다.
- 프리토킹 buttons/앱: 코스 2개 그대로. 서버가 «지금 차시에서 어느 코스가 열려 있나» 를 주는 API 1개(§5).

## 4. 시드 적재 — `scripts/curriculum/load_cur_seed.py`
1. cur_topic·cur_function ← 시드 (UPSERT by code)
2. cur_item ← 시드 vocab(10,636)·grammar(462) + 옛 learning_item chunk 46 복사 (UPSERT by (language, kind, key))
3. cur_lesson ← 레벨1 3차시(청크 15/15/16, 코드 L1-S01-1…) + 시드 488 (no 는 +3)
4. cur_lesson_item ← 시드 grammar_keys/must/core/support 순 seq + 레벨1 청크
5. 검증: 행 수 = 시드 불변식과 일치 · 모든 lesson 의 item_count = 실제 행 수 · no 연속 1..491
- 멱등 — 두 번 돌려도 같다. 운영 DB 도 «추가만» (기존 테이블 무변경) 이라 지금 통화에 영향 0.

## 6. 별건으로 미루는 것 (설계에 못 박아 둠)
- 레벨테스트 → cur_member_progress 시작 차시 연결(지금은 레벨테스트가 member.korean_level 만 씀). 그 전까지 새 회원은 no=1 부터.
- 이어하기(5분 조각)의 진도 이월 — 새 경로는 cur_member_item 이 서버에 있어 조각2 가 «남은 항목» 을 그대로 잇는다(옛 경로의 §0-3 문제가 구조적으로 해소). 오답 목록 이월은 cur_member_item.quiz_failed_count 로 가능.
- 다국어(en/fr/ja/vi/zh) 커리큘럼은 language 축만 두고 시드는 ko 만.
- 옛 테이블 폐기 시점 — 프리토킹까지 새 경로가 운영에서 돈 뒤.
