## 4. 왜 이렇게 됐는지 (추정) — 같은 실수의 재발 방지

`coda_ㄱ`·`coda_ㅂ` 의 한국어 `how_to` 2번째 줄은 **「붙인 채로 소리를 멈춰요」** 입니다.
그 둘은 **파열음**이라 소리가 실제로 멈추는 게 맞습니다(en: "Keep it there and **stop the sound**" — 정확합니다).

**`ㄹ` 은 유음입니다** — 혀는 붙어 있고 **공기는 양옆으로 계속 흐릅니다**(그 과의 3번째 줄이 그렇게 적혀 있습니다).
번역 시 ㄱ·ㅂ 의 「stop」 패턴이 ㄹ 로 옮겨간 것으로 보입니다.

⇒ 앞으로 받침 과를 번역·검수할 때 **파열음(ㄱ·ㄷ·ㅂ)과 유음(ㄹ)·비음(ㄴ·ㅁ·ㅇ)을 갈라야** 합니다.
