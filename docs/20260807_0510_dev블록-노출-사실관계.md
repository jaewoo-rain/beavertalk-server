# dev 전용 블록이 실서비스에도 열려 있다 — 사실관계와 조치 (2026-08-07)

> 캐스케이드 쪽 조치만 이번에 했다. **나머지는 별건**(bt-back 이 잡는다). 이 문서는 그 별건을
> 잡는 사람이 사실관계를 다시 조사하지 않게 하려고 남긴다.

## §1 사실 (실측)

```
운영 app-api  /health        → {"status":"ok","env":"test"}     ← "prod" 가 아니다
Cloud Run env  ENV = "test"
main.py        if settings.ENV != "prod":   → **운영에서 참**
```

그러므로 "dev 전용"이라고 적힌 그 블록은 **실서비스에도 마운트된다.** 블록 위 주석
("운영(prod)에는 노출하지 않는다" / "prod 에는 마운트조차 하지 않는다")은 **사실과 반대였다.**

⚠ 이건 새 발견이 아니다. 같은 파일 구독 도구 쪽에 이미 이렇게 적혀 있었다 —
"실서비스(app-api)의 ENV 는 'prod' 가 아니라 'test' 라 이 블록이 실서비스에도 노출된다".
**할인·구독 도구는 알고 `CurrentAdmin` 2차 방어를 붙였고, 캐스케이드에는 안 붙였다.**

### 틀린 주석이 남의 판단이 된 사례
클라 쪽이 저 주석을 1차 자료로 읽고 "prod 백엔드면 소켓이 안 열린다"를 **안전장치로 세고
있었다.** 주석 한 줄이 다른 팀의 설계 전제가 됐다 — 그래서 이번에 문구를 사실로 고쳤다.

## §2 지금 노출 상태 (2026-08-07 실측)

| 경로 | 운영 | 비고 |
|---|---|---|
| `/__cascadedemo` | **404** | 운영이 옛 이미지라 캐스케이드 코드가 아직 없다 |
| `/__levelcalldemo` | **200** | 실제로 노출돼 있다 |
| `/__dev/login` | 405(GET) | 라우트 존재. ⚠ **권한 상승 아님** — `sign_in_with_password` 라 이메일·비밀번호를 아는 사람이 자기 토큰을 받는 것뿐 |

⛔ 캐스케이드는 "지금 열려 있다"가 아니라 **"다음 prod 배포 순간 열린다"** 였다.
그래서 급한 건 아니지만 **prod 배포 전에 반드시** 였다.

## §3 캐스케이드가 열렸을 때의 실제 위험

`verify_token` 이 있으므로 미인증 공개는 아니다. 위험은 그다음이다:

- **인증된 아무 계정이나 세션을 열 수 있고 LLM·TTS 가 실제로 돈다**(원가가 나간다)
- `call_id`·DB 연동이 없어 **누가 얼마나 썼는지 사후 추적이 안 된다**
- dev 훅(`__test_beaver` 등)도 같이 열린다

## §4 조치 — 전용 스위치(`CASCADE_ENABLED`, 기본 False)

```python
if settings.ENV != "prod":
    if settings.CASCADE_ENABLED:      # ← 캐스케이드 블록만 한 겹 더
```

왜 이 방식인가:
- `CurrentAdmin` 은 **WS 라우터에 붙이기 어렵고**, 붙이면 사장님 데모 계정이 관리자가 아닐 때 막힌다
- `ENV` 값을 바로잡는 게 근본이지만 **같은 조건을 쓰는 다른 블록이 동시에 닫힌다** —
  영향 범위를 재야 해서 별건이다
- 전용 스위치는 **ENV 가 틀려 있어도 안전하다.** 깨진 게이트에 기대지 않는 것이 요점이다

⚠ **demo-api 에 `CASCADE_ENABLED=true` 를 넣어야 데모가 산다.** 코드만 배포하고 env 를 안 넣으면
`/__cascadedemo` 가 즉시 404 다 — 배포와 같이 나가야 한다.

테스트(`tests/test_cascade_gate.py`)가 네 가지를 못박는다: 기본 꺼짐 / 켠 곳만 열림 /
**ENV="test" 여도 스위치가 닫으면 닫힘** / prod 는 스위치가 켜져 있어도 안 열림.
⚠ 라우트 목록이 아니라 **실제 응답**으로 검사한다 — 도메인 라우터가 서브앱으로 붙어
`app.routes` 에는 안 보이기 때문이다(그걸 모르고 검사하면 "안 열렸다"를 잘못 통과시킨다).

## §5 남은 것 (별건)

1. **`ENV` 값 정정** — 운영 app-api 를 `ENV=prod` 로. 같은 조건을 쓰는 블록 전체의 영향 범위를
   먼저 재야 한다(무엇이 닫히는지 목록부터).
2. `/__levelcalldemo` 등 **같은 블록의 다른 항목** — 지금 실제로 노출돼 있다. 항목별로
   ①닫을지 ②`CurrentAdmin` 을 붙일지 ③전용 스위치를 줄지 결정.
3. `/__calldemo` 는 라우트만 남고 파일이 없어 **500** 이다(`scripts/call_demo.html` 부재).
   닫든 복원하든 정리 필요.
