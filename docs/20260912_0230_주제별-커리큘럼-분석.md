## 3. 사장님 큰 틀에 대입하면
```
회원 진도 = 차시 번호(no).  차시 no 의 ① 표현학습 → ② 프리토킹 → no+1
① 표현학습 재료 = grammar(1~3) + must_use_vocab(≈8, «필수») + vocab(≈13, «핵심»)   ⚠ 지원어휘(9)를 가르칠지는 결정 필요
   — 지금 표현학습은 «레벨의 항목 풀에서 18개 랜덤» 인데, 차시 기준이면 «이 차시 항목 전부(평균 15개)» 가 한 통화 분량과 맞다.
② 프리토킹 재료 = situation + partner(상황 묘사용) + dialogue(모범 6턴) + probes + success 조건
   — 비버 = 선생님 페르소나 그대로(캐릭터). ai_roles 의 «당신은 반 친구이다» 1인칭 지시는 그대로 못 쓴다 → 상황 재료로 재작성.
   — 성공 조건(학습자 3턴·핵심어휘 2~4개·목표 문법 1개)은 표현학습 퀴즈처럼 **서버가 잰다** — 어휘 사용 측정은 자모·불규칙 활용 처리(ko_vocab_match.py)가 있어야 맞는다(감사 §11.2: 없으면 절반을 놓침).
```
