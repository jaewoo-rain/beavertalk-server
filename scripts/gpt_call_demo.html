🦫 BeaverTalk — GPT(OpenAI Realtime) 표현학습 통화 QA 콘솔

통화를 들으면서 WS 로 오는 모든 것을 화면에서 본다. 마이크는 localhost 또는 https 에서만 동작한다.
⚠ 이 데모는 실제 통화다 — 전사·판정·진도·원가가 서버 DB 에 그대로 기록된다. 엔진(OpenAI/Gemini)은 서버가 고른다. 이 페이지는 엔진을 바꾸지 못한다 — 콜타입만 고른다.
⛔ OpenAI 로 가려면 서버 쪽 4가지가 동시에 참이어야 한다(하나라도 어긋나면 조용히 Gemini 로 간다 — 엉뚱한 엔진을 QA 하게 된다): ① GPT_API_KEY 있음 ② OPENAI_REALTIME_COURSES 에 그 콜타입 포함 ③ CUR_ENABLED=true + 그 언어 커리큘럼 시드 있음(아니면 옛 경로로 폴백) ④ 코스가 expression 으로 확정(엔진 분기는 표현학습 자리 하나다 — call_session.py:3741).
⚠ 엔진 이름은 WS 프레임에 안 실린다 — 확인은 서버 로그(live:openai-realtime-*)다. 대신 아래 조각 필드 수신 칸이 0 이 아니면 Gemini 경로일 가능성이 크다(OpenAI 는 조각을 안 보낸다).
API base 인증은 이 서버가 발급한다(/__dev/login) — 페이지에 Supabase 설정이 없다
