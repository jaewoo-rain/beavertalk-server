🦫 BeaverTalk — 레벨테스트 통화 데모

첫 통화(레벨 측정)를 브라우저로 체험. 비버가 대화하듯 실력을 떠보고, 끝나면 레벨(1~13)이 판정·저장됩니다. ⚠️ 이 데모는 테스트 계정의 레벨을 실제로 저장/덮어씀. 마이크는 localhost/https 에서만 동작.
API base 인증은 이 서버가 발급한다(/__dev/login) — 별도 Supabase 설정이 없다
STEP 0 · 로그인 (누구 계정으로 테스트할지)
STEP 1 · 레벨테스트 통화 (편하게 대답하세요 · 선택한 시간 후 자동 종료)
캐릭터 ID 학습 언어(target) 모국어(안내 언어) 통화 길이
대기
STEP 2 · 분석 결과 (레벨 · 요약 · Baba의 한마디)
통화가 끝나면 자동 판정됩니다…
STEP 3 · 새로 배운 표현 (💾 저장연습 = 점수반영 · 🎤 그냥연습 = 미반영)
표현을 소리 내 읽고 버튼을 눌러 녹음→다시 눌러 채점. 저장연습은 공식점수·소리집계 반영, 그냥연습은 이력만.
일반 통화(새 표현 추출) 후 표시됩니다.
STEP 4 · 발음 결과 (소리별 정확도 · 문장 결과 · 최근 5세션)
저장연습으로 채점한 소리들이 집계됩니다.
